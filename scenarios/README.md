# 剧本数据目录

把经过核对、可公开提交的剧本 JSON 放在此目录。服务启动后会自动发现所有 `*.json`，逐一通过引擎的严格校验，
并按剧本内的 `id` 加入 Web 大厅目录；无需修改 Python 或前端代码。

格式以 `examples/*-tutorial.json` 为准。文件包含身份、规则和事件当事人等完整答案，不应直接交给主人公玩家。
`GET /v1/scenarios` 只返回标题、规则集、天数和可选/默认轮回数，不会返回这些秘密。

当前收录了根据项目维护者提供的卡图人工核对录入的 22 个官方剧本：FS 2 个、BT/BTX 11 个、
MZ 4 个、MC 5 个。BT 卡按 BTX 规则集运行。原始参考图片位于被 Git 忽略的 `references/`，
不会随仓库发布；文件名中的规则集前缀记录对应资料批次。

部分卡面允许多个轮回数，JSON 用 `loop_options` 保存全部合法值，并以 `loops` 表示大厅当前采用的默认值。
`role_slots` 仅用于记录卡面明确给出的、与通用速查推导不同的精确身份槽；`special_rules` 只接受引擎已经显式
支持并校验的剧本规则。新增剧本不得用这些字段绕开普通校验。

# 未来事件防守成本（2026-10-15）

## 可选算法

开眼新增 `future_incident_policy="legacy"|"impact"`，默认保留 legacy；CLI 为 `--oracle-future-incident-policy`。公平粒子内部 helper 仍保留旧策略。未新增大厅 AI ID。

旧日末估值有一个未封顶的未来当事人不安项，但统一权重仅 0.035。事件进度本身又在临界值封顶，因此不安 2 和 3 都被当成已达临界，过高不安的后续防守成本低估。

impact 版只替换这一未来项：

`防守成本 = 0.2 × 当前局面的事件影响 × 当事人不安 / (1 + 距离事件的天数)`。

事件影响复用 `ScenarioConditionedEvaluator.incident_impact` 的既有规则条件权重。普通事件 0.18，医院随密谋为 0.18／0.38／0.70；关键人物／亲友自杀和有关键受害人的谋杀更高。没有按剧本 ID 或特定角色名调分。当前日末存活的优先级不变，也没有把这个分数作为信念概率或硬约束。

临时工死亡后替身成为实际当事人的逻辑提取为共享规划解析；事件路线、未来项及开眼技能上下文使用一致的当前当事人。未登场／已死亡角色不计算该项。原始规则执行没有修改。

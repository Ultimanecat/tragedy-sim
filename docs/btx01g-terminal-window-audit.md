## 原因与修复

策略黑方旧轨迹的第二／三轮第五日，偶像与男学生在都市单独相处。偶像在日末强制能力中死亡，随后立即轮回失败。引擎在中断时未发 `mandatory_window_resolved`，已有正向杀人狂 witness 依赖这个完成标记，因而遗漏该次攻击来源。关键人物死亡证据已有，攻击者身份约束遗漏。

新增独立组件 `btx.terminal_mandatory_serial`，仅从公开日志读阶段：未完成的日末窗口中，死亡尝试与失败事件均为 `phase: day_end`，才产生首个目标的 `mandatory_serial_route`。同轮同日、替身／旧日志／可选阶段均检查；完成窗口原组件不变，不修改规则引擎或玩家显示。

候选保留初始杀人狂，及病毒剧情下本轮已到不安 3 的初始普通人。旧轨迹男学生不安达到 3，故不能在所有剧情假设下都直接确定其初始身份。矩阵、硬路线构造及终猜 MAP 复用现有表示，无新身份特判。

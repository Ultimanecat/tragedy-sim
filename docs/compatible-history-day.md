# 公平日末内核：兼容隐藏历史（2026-10-18）

T0.4增加可选的原生历史重放，连接[公开后验桥](public-posterior-day.md)。完整setup假设与当前私密状态分别处理；默认AI、房间接口和SSE不变。

## 输入与覆盖

输入只有假设剧本、授权团队事件／当前视图、红方自己的完整命令记忆。公开剧本ID仅作展示元数据，不查询剧本库的秘密内容。重放从假设剧本初始化开始，使用原生`Game.transition`：

1. 每个中间节点产生的结构化事件必须是已收到事件的前缀。文案、翻译与展示标题不用于筛选。
2. 过去已经揭示的牌面约束其原放置动作，免去重复枚举已公开的牌。红方动作严格按自身命令记忆重放；其余剧作家动作完整枚举，保留能力顺序和拒绝。
3. 完整规则状态、已消费的红方记忆位置和授权事件前缀相同时可合并。私密能力使用字段、当前／初始身份、上一轮死亡／好感等均入规则键。
4. 到达本日出牌根后，完整授权快照与自身记忆必须匹配。当前黑牌仅用合法占位面恢复已公开靶位，随后由完整黑牌域恢复物理手牌并枚举全部牌面。

`complete`表示已穷尽**所提供事件和自身记忆**允许的历史集合。额外但未记录的中间观察可能缩小这个集合；当前结果对该保守支持求解。它不提供人类策略的历史似然，也不将setup后验声称为已校准的行为概率。

规则状态键的字段审计沿用FS范围；不支持的键、深度上限或节点预算中断均标为不完整。即使中断前找到部分合法根，也不能用它们认证全部历史覆盖。

## 同一剧本的历史不分摊概率

令h为setup类型，S[h]为其兼容历史当前状态，b为本日完整黑牌：

```text
V = max_x sum_h p[h] min_(s in S[h], b) sum_r x[r] A[h,s,r,b]
```

`HistoryDayGame`把`(history_index, black_faces)`作为同一个世界块内的黑方列，红方在所有历史共用一个根策略。历史和牌面在红方私有随机抽样前选择，揭牌后能力仍按正式规则执行。每个h的原质量只计一次；不对历史数量均分质量，也不把每条历史复制成一份完整概率。

这是给定setup权重及兼容历史支持的稳健博弈。它保留了黑方过去选择的未知性，结果范围与“已知当前完整私密状态”的基准分开标注。未来若要给历史分配行为概率，须另行定义、校准和冻结该模型。

## 工作量与失败处理

- `history_node_limit`是所有选中setup世界共享的证据预算，独立于行动`WorkLimit`；默认关闭历史枚举，需显式配置。`history_max_depth`默认1024。
- 完整重放无兼容根时记录`no_compatible_history`；即使允许状态先验，也不覆盖这个已证实矛盾。
- 重放不完整时，严格模式把该世界质量保留为未知；显式开启`allow_state_prior`才可退到旧快照先验，并记录先验质量。
- 不重新归一化成功根的质量。完整类型覆盖、无失败质量及无状态先验质量，才可声明所定义有限模型完整。
- `history_audits`逐世界记录完整性、支持根数、节点／边、停止原因及合并数；这些仅在私有诊断报告中出现。

## 验证与反例

原生回归覆盖：第2天重建、轮回失败后的重置与上一轮死亡记忆、私密输入拒绝、错误终盘／自身命令、预算截断、原质量保留以及多历史黑方最小化。端到端测试确认历史证据预算独立于行动搜索。

## 后续边界

历史支持不解决能力阶段的信息集策略优化。当前红方仍采用同一冻结的授权续演政策；下一步改进政策及完整信息集能力选择，再进入T1–T3。更长历史可能需要增量支持维护和分阶段缓存，预算耗尽继续保留未知。

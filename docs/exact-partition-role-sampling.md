# 精确分区身份／剧情后验抽样（2026-10-14）

状态：FS／BTX 实验路径已接入；默认保持 prior 矩阵重要性提议。没有新增大厅 AI ID，黑方内部回应模型和终猜策略保持原配置。

## 抽样目标与密度

复用终猜联合概率组件的互不重叠身份分区。每组有 `C` 个合法完整身份表，每个表在相容剧情 `p` 下的质量为 `w_p`，组内所有表的质量与约束判定相同。设 `M = Σ_p w_p`，全空间质量为 `Z = Σ_group C M`：

1. 以 `C M / Z` 的概率选分区。
2. 用整数 `randrange(C)` 选组内完整身份表的排名；按剩余身份数量、角色允许域和亲友性别限制的后缀计数解码，条件均匀概率为 `1/C`。
3. 在所选身份表的合法剧情中，以 `w_p/M` 选择剧情。

完整身份／剧情样本的密度为 `q = w_p/Z`。分区代表只用于查询和展示，抽样覆盖所有组内完成方式；不能只抽 MAP 代表，也不能相乘角色边际。重复抽样保留，完整 validator 和 matcher／共同目标验证每一个输出。分区质量与实际世界不一致时直接报错，不通过重抽隐藏归一化错误。

该路径对当前 `uniform-printed-casts-v1` 身份／剧情模型直接后验抽样，浮点软权重仍有机器精度误差。这个模型使用启发式软似然，精确抽样不保证先验和似然已校准。角色后验与当事人、暗牌目前独立近似；返回的事件行是角色合法性占位，随后由原当事人组件替换。角色样本的 q 不包含当事人／暗牌密度。

## 与行动规划的连接

- `role_posterior()` 保留固定 `min(192, capacity)` 次诊断抽样；用共同 `target/q` 处理，理论权重相同，有限样本仍有边际误差。ESS 为批次大小只说明抽样权重稳定，不能证明世界覆盖充分或模型正确。
- 行动世界直接从完整分区重新抽取，随后组合当事人和暗牌；不从有限诊断池再抽，避免双重抽样误差。全部三牌候选在同一批行动世界上评价。
- 小角色空间也可显式测试该抽样路径；默认路径仍保留原完整枚举。相同分布的不同随机编码会改变小批次决策，单个 seed 的胜负变化不能证明目标分布优劣。
- 同一合法观察与 witness 集合复用分区，证据变化后重新求解；外部可变 witness 已复制，独立分区 RNG 不影响默认 RNG。
- 工作上限默认 100000。超限／不支持的因子明确记入 `role_partition_fallback`，回退原矩阵重要性路径；已证明支持为空时返回空集合，不回退到非空猜测。失败分区不返回部分样本，也不消耗分区 RNG。

分区只表达已编译的证据模型。现有公开状态重建器复制可见快照、组合相容暗牌，未新增所有历史命令的精确似然或重演过滤。真实对局另以完整 replay 核验硬证据／私密安全初始知识，不能称为完整历史后验。

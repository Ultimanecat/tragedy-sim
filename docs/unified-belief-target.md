# 共用概率目标（2026-10-13）

## 边界和目标

矩阵保留硬状态、联合约束及边际概率。当前优先统一概率模型，不调整行动估值，不按剧本 ID 调权。

FS／BTX 身份／剧情目标：

`未归一化后验(world) = 初始先验(world) × 硬兼容指示 × 2**角色证据软分`

初始先验选择：在公开角色组成下可成立的剧情组合等权；每个剧情组合内，符合印刷角色／数量／属性限制的完整初始身份分配等权。可选数量及局外人／模仿者形成的分配均计入该剧情的初始分配数。剧情组合的共同归一化常数可在 MAP／相对权重中省略。

已观察身份、剧情和 witness 只用于后验，不能重算初始分母。这一先验是明确的建模选择，不声称实际剧作家按此方式编剧；后续调整需要跨剧本校准。

现有软分保留作为启发式对数似然，尚未校准为真实事件生成概率。硬规则、软行为证据与行动奖励分开；规则硬结论不参与调参。

## 实施顺序及验收

1. 共用目标组件接入完整／有限身份库和终猜，初始分配数用与矩阵相同的角色／数量支持计算；拆分随机流。用枚举检查各入口同一世界权重一致、观察不改变先验、证据重复刷新不重复累积。
2. 矩阵正常提议显式记录 q，评价权重包含目标／q。重复抽中具有统计质量，不能静默去重后仅按目标重新取样；旧混合路径保留为短期基准，随后切换主线。
3. 当事人合法整套分配采样，共用条件化概率；暗牌行为先验单独审计。
4. ESS／误差诊断和自适应补样，随后短跨日与终局信息价值；每步消融，固定对手、候选和预算，不同时改所有层。

生成器使用矩阵硬域及完整 matcher，无候选保留诊断，不放松证据。后验的联合约束继续保留，矩阵边际不独立拼接；最终猜测继续选合法完整分配。

## 防过拟合

- 先用无特定剧本 ID 的小模型枚举核对，再检查真实失败轨迹。
- 旧个案修改分类为规则修复／硬证据／软似然／提议／行动估值，分别做消融；不把所有变化归为先验改变。
- 固定工作量与秒／分钟墙钟分别报告。调试剧本和留出剧本、seed 独立，Easy 单列。
- 报告直接存活、整局胜负、终猜正确数、候选覆盖和概率校准；局部案例不作全局棋力结论。

执行状态以 [路线图](future-roadmap.md) 为准；历史 [逐步排查](matrix-regression-step-audit.md) 仅描述当时算法。

## 提议校正切片

矩阵传播后的每个数量／域变体有 `N_v` 个完整分配，变体数为 `V`。现有构造在变体内按可完成数量抽样，给出的提议密度为 `q(world)=1/(V*N_v)`。完整 matcher 的剩余拒绝产生共同接受归一化因子，标准化重要性权重时可消去。

新路径已记录每次有效提议及 q，以 `target(world)/q(world)` 计算抽样质量。重复抽中保留；聚合同世界时把质量相加。缺少 q 的旧持续库不与新路径静默混合。当前矩阵开发开关启用该受控路径，验证正确性与 ESS／耗时后再评估切换主线；旧提议只保留短期对照，不新增长期大厅 AI 模式。

小空间枚举目标概率和提议概率，验证重要性校正恢复目标、重复质量保留及非法硬域拒绝。后验估计器、有限搜索世界、materialize 拒绝各自记录，避免把完整目标的正确性当作有限批次可靠性的证明。

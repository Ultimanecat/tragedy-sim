# 公开后验到日末博弈：联合质量与状态重建（2026-10-18）

T0.4的后验桥已接到 [分块公平内核](exact-day-fair-worlds.md)。入口只接受授权团队视图、自己的历史命令和工作量配置，不接受真实`Game`或真实剧本。默认AI、房间入口与SSE不变；以下报告和假设世界为私有诊断数据。

## 1. 后验来源与概率定义

复用现有矩阵约束、witness编译器及完整角色分区：`PartitionRoleSampler`／`JointGuessProbabilitySolver`提供角色计数和每组的剧情分解，`JointCulpritPosterior`提供带跨日重复限制的当事人联合支持。已有默认采样器与新桥共用当事人软似然函数，未改变默认采样顺序或RNG。

角色先验继续使用`uniform-printed-casts-v1`：初始剧情组合等权，各组合内合法印刷身份配置等权；证据限制支持并乘软witness似然。桥使用整数计数形成有理数先验，`exp2(soft_score)`的既有浮点值冻结为十进制有理数，随后在**完整计数分区**上归一化。模型版本为`factorized-setup/rational-prior-frozen-exp2-v1`，与旧浮点目标作数值一致性回归；启发式软似然没有校准成人类概率。

角色／剧情和当事人按当前已定义的因子模型相乘，不从单角色矩阵边际的乘积构造整套身份。新witness无法分类或完整分区超预算时，返回不可用原因，不用截断分区伪造归一化常数。组合世界也经过完整matcher检查；发现未分类的跨因子约束时中止该模型。

本日暗牌是黑方完整合法行动域中的对抗列，不在此处按暗牌倾向抽样。状态重建使用的占位牌不限制后续完整黑牌域。

## 2. 惰性联合世界与遗漏质量

- 角色流按每个完整身份／剧情世界的质量排序，以整数rank展开计数分区，不把MAP代表当成采样总体。
- 当事人流用精确最大后缀界展开合法安排，保留跨日重复限制，无须先遍历笛卡尔积。
- 二维优先队列按两流的联合质量取世界；等权时跨角色／当事人维度轮转，避免先消耗一整条字典序行。
- 取K个世界后保留其原质量，总和不足1的部分继续未知。后验选择不使用行动RNG，也不消耗行动预算。

FS01初始公开视图有5430种角色／剧情类型、30种合法当事人安排，共162900种联合类型。前5个世界各为1/8100，总质量1/1620；不会变成五个各1/5的世界。已知全部身份但未知当事人时，仍有30种联合世界，不能仅凭身份支持完整宣称联合后验完整。

同一快照可以重复取更长前缀，已有世界及质量保持一致。选择记录与原公开快照绑定，不能将旧质量直接用于另一张棋盘。

## 3. 当前隐藏状态单独处理

完整setup假设不保证知道当前的全部私密能力使用历史。桥把三种情况分开：

1. **唯一初始化重放**：第1轮第1天，从假设剧本初始化；每个前置窗口只有一个合法动作时按原生引擎重放，再放置符合公开靶位的占位黑牌。检查结构化公开快照与自己的命令记忆，保留实际收到的公开文本。初始化有非唯一选择或快照不符时不认证唯一状态。
2. **兼容隐藏历史重放**：显式配置`history_node_limit`时，从假设剧本初始化重放授权事件和自己的完整命令记忆。已揭示牌约束过去放置，其余剧作家选择完整枚举；多种兼容当前状态作为同一setup下的对抗列，原质量只计一次。中断不认证完整覆盖，详见[历史支持设计与验证](compatible-history-day.md)。
3. **公开快照状态先验**：未启用或未完成历史重放时，须显式开启`allow_state_prior`。复用现有`PublicStateDeterminizer`，恢复授权答案、公开状态和自己的命令记忆，但隐藏历史仍是先验模型；标记`approximated_state_mass`，不赋予完整隐藏状态覆盖认证。完整重放已证实不兼容的世界不退回先验。

重建保留公开视图中的角色插入顺序，以保持数字目标菜单与角色的对应关系；身份计数仍用排序后的规范元组。手牌所有者、弃牌序、公开知识和自身命令不因假设排序而改写。

不可重建的世界进入`failed_mass`，不重试抽到成功为止，也不把成功世界重新归一化。只有联合类型全部覆盖、无失败质量、无状态先验质量时，才可声明该**已定义后验／固定续演模型**的覆盖完整。当前中途状态先验的数值界仅针对该重建模型，不能当成真实隐藏历史下的存活保证。

## 4. 端到端API与命令

```python
from tragedy_sim.day_game.public_day import solve_public_day

solved = solve_public_day(team_view, own_commands=own_commands,
                          world_limit=12, node_limit=100000,
                          time_limit_ms=10000)
# 只抽取已经选定的共同红方分布；不读取真实世界。
plan = solved.sample_card_plan(private_rng)
```

后验计数、witness与状态重建完成后才启动行动`WorkLimit`，证据时间独立记录。后验不可用时不返回伪造策略／证书，调用者可选择明确的基线回退。混合策略按有理数分母抽取完整三牌，三牌按当前队长顺序执行。

```powershell
python -X utf8 -m benchmarks.ai_public_day --view references/team-view.json --world-limit 12 --time-ms 10000 --output references/public-day.json
python -X utf8 -m benchmarks.ai_public_day --view references/midgame-view.json --own-commands references/own-commands.json --allow-state-prior --time-ms 10000 --output references/midgame-day.json
python -X utf8 -m unittest tests.test_day_game_posterior tests.test_ai_public_day
```

`--view`是完整未出红牌的FS团队视图，`--own-commands`仅包含主人公命令。默认拒绝中途隐藏状态先验，默认reference后端；可显式选择cached／compiled。公开剧本ID只作元数据，测试禁止通过`ScenarioLibrary.get`查询其秘密内容。

报告包含公开输入、模型版本、支持计数、选中／失败／状态先验质量、上下界、证据及行动耗时；没有接入JSON服务的玩家投影。

# BTX-01G：地点奖励越过风险比较（2026-10-12）

接续 [中断窗口证据审计](btx01g-terminal-window-audit.md)。本批不改 witness、世界提议、行动候选和规则，只修正公平粒子红方的评分汇总顺序。

## 反例

旧联合黑方轨迹第三轮第一日：红方身份样本中偶像为关键人物 12/12、医生为传谣人 12/12。黑方实际在偶像放密谋＋2、医院放密谋＋1、住院病人放不安＋1。采样的偶像暗牌里有 5/12 张密谋＋2，禁止偶像密谋的合法候选也已被评估，问题在评分。

旧实现把地点禁止密谋奖励 0.08 加进风险尾部。该根医院守卫原始尾分约 0.5997，加奖励后约 0.6797；偶像守卫约 0.6400，因而医院守卫被优先选中。主规则是“关键人物密谋达到 2，轮回末失败”，放过偶像的密谋会形成长期危险。

## 修正与同根消融

风险尾部保留模拟原始分数；地点守卫奖励仍存在于后置平均值／日末平均值比较。比较顺序保持：horizon 存活 → 当日存活 → 原始风险尾部 → 日末平均 → 综合平均。奖励不会越过前三项。即使当日都存活，风险更好的角色防守也应优先；风险相同时仍能鼓励地点防守。

旧根输入 `btx01g-terminal-serial.json`，工具输出 `btx01g-raw-risk-roots.json`，源码指纹 `8869191763565350ba74c81f780cc1de16de8edd088144c3ec6adac9ae4362eb`。选择 joint、第三轮第一／三日，8 候选、12 世界、1000 ms、深度 8；同时生成日末／轮回末及开眼诊断，共 14 个计划。

第一日新公平日末规划器选择“禁止偶像密谋＋禁止巫女移动＋压住院病人不安”，原始尾分 0.64610。对这次相同候选行、相同模拟分数重加旧尾部奖励，转选“禁止医院密谋＋禁止大小姐移动＋压住院病人不安”，原始尾分 0.60497、旧加分尾部 0.68497。这是同候选评分重排消融，未重新采样世界。第三日同根选择未改变，不声称解决所有跨日问题。

全知日末／长 horizon 的有限候选续演仍会失败，不能据此断言无解。真实规则以 [剧情与角色实现](../tragedy_sim/rulesets/btx/plots.py)为准：传谣人增加不安；偶像的密谋来自黑方行动牌，之前接续文档已订正。

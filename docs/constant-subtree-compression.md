# 常量子树压缩（T0.4）

T0.4 公平迁移的第一项：在不改变信息集博弈值的前提下，折叠所有原生后续动作终值相同的子树。当前只覆盖审定的 FS 原生引擎和 `day-survival-v1` 收益。

## 结论

- 实现已通过 12 项专项测试和 1100 项全量回归。
- 独立原生策略重放确认：压缩前后求解值一致，开眼最优值没有被当作常量。
- 公开 FS01／FS02 的有限信息集树在 10 秒预算内从「无法建树」变为 2.6–3.6 秒完成，分别折叠 8 个子树。
- 完整根域（`--mode full-responses`）仍未闭合：公开后验只选中 2/4050 的质量，黑方回应在 10 秒内只检查 65/720 列。常量子树压缩让第一轮迭代得以完成，T0.4 保持进行中。

## 问题

信息集树按所有原生合法动作展开。大部分日末子树在同一天内无论双方怎么行动，终值都锁死为 0 或 1。继续展开这些子树只消耗节点预算，不增加任何策略信息。

不能直接按「开眼最优值」或「固定对手当前选择」折叠。折叠必须证明：在该子树内，双方所有合法续演都到达同一个终值。预算截断、缓存未命中和策略依赖的值都必须保留为 `[0,1]` 未知。

## 算法

新增 `tragedy_sim/day_game/universal_range.py`：

- `UniversalDayRange.probe(world, position, work, node_limit, max_depth)` 枚举当前控制方的全部合法动作，递归求原生极小极大终值。
- 返回 `NativeRange(minimum, maximum, exact)`：
  - 全部子节点同为 0 或同为 1：返回精确常量。
  - 某个子节点已经证明同时存在 0 和 1：返回精确 `[0,1]`。
  - 其他情况：返回未知，不写入缓存。
- 只有精确结果进入容量受限的 LRU 缓存，键为 `(版本, 日位置, rule_state_key)`。同一状态若出现矛盾常量直接报错。
- `MIXED` 表示已证明两端都能到达，不是近似值。
- 达到时间／节点／深度上限时保留未知，并记录 `cutoffs`。

接入 `information_game._Builder`：

- 每个节点先做一次受 `range_probe_nodes` 限制的探测；探测到常量时直接生成终端叶。
- 子树展开完成后，如果所有子节点终值相同，也折叠为常量；这层可以自底向上填充缓存。
- `universal` 标记只在「全部原生动作都被覆盖」时成立。固定对手策略下选中的路径不能写入通用常量缓存。
- 响应树（固定红方或黑方策略）不再为已冻结一方的未选动作额外探测，只复用已有通用证明。

缓存与探测共享 `WorkLimit`，但单次探测有独立节点上限；预算耗尽时回退未知，不产生未核验策略。

## 安全边界

- 只允许审定的内置 FS `Game`；其他规则集或未识别状态直接失败关闭。
- 只有 `[0,1]` 两端都有见证时才缓存 `MIXED`。
- 未采样到不等于 0，预算截断不等于常量。
- 固定策略路径的常量只对当前响应树有效，不进入通用缓存。
- 信息集树压缩与未压缩必须解出相同界；新增测试和独立原生重放都检查这一点。
- 该证明只适用于当前 `day-survival-v1` 收益；T1／T2 更换续局值后必须重新审计。

## 验证

新增 `tests/test_day_game_universal_range.py`，12 项通过，覆盖：

- 10 个随机局面的原生全动作结果与 reference／cached 两种后端一致。
- 「已知世界最优值为 1」不会被误判为通用常量。
- 预算截断不缓存为精确 `[0,1]`。
- 缓存复用不忽略手牌、弃牌等物理资源。
- 容量淘汰、未知状态键、非法日位置失败关闭。
- 固定策略的跳过路径不写入通用缓存。
- 压缩前后控制局面的精确值与策略扩展一致。
- 共享信息、私密常量失败不会泄漏世界。
- 查询／拒绝分支压缩后仍保持值 1。

## 公开 FS 根预算验收

本阶段的验收定义为：

1. 同源码、同输入、同预算下比较压缩与未压缩。
2. 报告实际用时、停止原因、树节点、折叠数和可靠界。
3. 不允许把未完成的回应或缺失质量包装成认证。
4. 完整根域闭合必须另外满足：后验质量完整、双方回应覆盖完整、界闭合。

当前结果满足 1–3。第 4 条不满足，原因是：

- 公开后验只采样 2 个 setup 类型，缺少 4049/4050 的质量。
- 冻结红方策略下，每个黑方列仍要构建日末树；10 秒只能检查约 65 列。
- `unrepresented_mass` 是缺失质量导致的预期停止，不代表已证明对抗安全。

## 复现

```powershell
python -X utf8 -m benchmarks.ai_information_day `
  --view references/ai-calibration/2026-10-18/public-official-fs-01-first-script.json `
  --warmstart references/ai-calibration/2026-10-17/bayesian-day-seeds.json `
  --mode selected --world-limit 2 --black-limit 2 --nodes 100000 --time-ms 10000 `
  --output references/ai-calibration/2026-10-21/fs01-selected-10s-compressed.json
```

关闭压缩做同预算对照时加 `--no-constant-compression`；需要更大缓存或探测上限时使用 `--constant-cache`、`--constant-probe-nodes`。

# 十周年归档剧本兼容性复核

复核日期：2026-10-10。引擎基准：`839e72a`（BTX+ / MZ+ 基础扩展已实现）。

## 结论

已归档的 9 个 BTX+ 与 1 个 MZ+ 剧本全部带有额外社区规则，当前新增可玩剧本数为 **0**。原有大厅中的 BTX+ / MZ+ 教学剧本仍可游玩。

保持用户此前「社区额外规则暂不考虑」的范围：不删除固定出牌、改写轮回数、替换自定义角色或取消隐藏信息来强行开放。当前工作只修正归档数据、兼容性诊断和测试，没有修改游戏引擎或前端。

## 修正内容

- 十周年身份「因果残片」现在完整映射为 `fragment`。
- 按当前模组选择同名规则；例如 BTX+-11 的恋爱风景线映射为 `love`，排除旧数据中误用的 HSA `love_hsa`。
- 支持身份在前、角色在后的原文行，并保留转校生／临时工的歧义。
- 支持身份后紧接括号备注；BTX+-11 从漏录的 1 名恢复到原文全部 12 名，备注仍保存在源配役行中。
- 规范化「患者」「大树」等别名。
- 牛头人等未支持的自定义身份保留在归档候选及原始配役中，显式标为未完成，不跳过该角色。
- 移除过时的「不支持 BTX+ / MZ+」诊断，替换为当前具体阻碍。

## 资料结构与校验

原始 `public_setup`、`source_setup_text`、`source_configuration_sections`、`source_filename` 保持原样。新增 `compatibility_review`：

- `engine_revision` / `reviewed_on`：评估基准。
- `source_digest_sha256`：上述四项原始来源字段的 SHA-256，防止修正候选时误改原文。
- `ruleset_supported`：十周年规则集是否支持。
- `base_setup_valid`：忽略额外社区规则，仅检查规范化配置能否通过剧本校验。
- `required_features`：稳定 ID 与中文说明组成的未满足条件清单。
- `normalization_issues`：缺失参数、角色替换、择一配役等转换问题。
- `executable` / `decision`：本批均为 `false` / `retain_archive`。

档案、社区索引及总索引同步保存复核结果，分类仍为「社区／有特殊规则」。状态仍为 `blocked_special_rules`；目录只加载 `scenarios/` 顶层文件，源档案不进入玩家 API。

测试核对来源摘要、三个位置的复核一致性、当前校验结果、完整配役和模组专属规则 ID，以及未支持自定义身份的保留。执行 `python -m unittest tests.test_scenario_library tests.test_scenario_import_data tests.test_anniversary`。

验证结果：相关测试 45 项通过，完整后端回归 664 项通过。前端和引擎代码未变，本批没有新增棋力评测结论。

## 后续范围

归档筛选已经完成。本批暂无可开放候选，额外社区规则不列入近期实现。若以后明确要支持某个剧本，先定义其特殊规则模块及信息投影，再录入可玩文件。十周年公平 AI 的候选世界／witness 可在基础教学剧本或人工提供的标准 `+` 剧本上独立推进。

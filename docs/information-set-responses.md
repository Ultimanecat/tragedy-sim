# 完整域信息集回应与全域界（2026-10-18）

T0.4在[原生信息集能力树](information-set-day.md)之上增加冻结策略、完整物理根域回应及策略生成。`selected`仍表示有限根域，新增`full-responses`才执行全域分离检查。默认房间AI不变，以下输出均为私有诊断。

## 1. 冻结与域外延伸

每轮受限树同时优化根三牌混合策略及原生技能政策。红方下端解和黑方上端解分别形成合法策略见证；未访问的信息集统一使用确定性的`next`／`pass`优先、否则合法规范首项的延伸。政策只接受授权信息集身份和合法菜单，不接收真实世界标签。已记录信息集返回非法动作时直接报错，不偷偷换政策。

`FrozenBehavior`复制并规范化概率表，版本摘要包括玩家、全部条件概率及回退定义；`FrozenInformationStrategy`还包括共同红牌分布、按setup条件化的黑牌分布。每次回应过程中版本和收益定义冻结。不同候选不得使用随候选重新训练的对手政策。

黑方根行动身份由实际牌面、目标槽和兼容历史编号构成，候选重新排序不会改写其身份或recall。根黑牌在红方本次私有抽样前提交；揭牌后的能力才合法响应已公开的红牌。

## 2. 稀疏序列流最优回应

固定对方实现向量后，将自然概率、对手到达率和终局收益累加为己方序列系数c。己方信息集I的所有动作共享一个前置序列；多个信息集可以拥有同一前置序列。

```text
W[s] = c[s] + sum_(I: parent(I)=s) opt_(a in I) W[sequence(I,a)]
```

红方opt为max，黑方为min。自后向前处理序列，得到合法纯最优回应；前向恢复实现概率。返回前独立复核非负流、目标值及每条稀疏流对偶不等式。生产路径没有枚举整套纯技能策略，也不调用LP。

10个固定seed的多阶段树，在随机生成的合法对手条件概率下，双方回应值与独立完整正常形式矩阵逐项一致。基础信息集／perfect recall规范及论文来源见[序列形式报告](information-set-day.md)；本节DP及其稀疏证书为项目实现，结论限定于给定树。

## 3. 全域回应

- **黑方**：每setup遍历完整黑牌域，固定同一根牌面，对红方根混合策略计算加权收益；之后才在原生能力树中求黑方最优回应。红方技能政策全程冻结。FS的揭牌是强制步骤，所有非平凡黑方能力发生在揭牌后，因此可以按已公开红牌分别计算后续回应，再对红方根抽样加权。禁止先看到红方抽样再替换根黑牌。
- **红方**：每个完整三牌候选在所有setup及其黑方条件根分布上构造同一信息集树，冻结黑方政策，将其行为概率作为自然分支。红方使用稀疏DP求一个共同技能回应，不能逐世界开眼优化后平均。
- 原生节点、深度、时间及显式树限制保留未知[0,1]。未检查的根动作仍按全局收益范围计界；找到可达效用极值时可提前证明回应值，不要求遍历剩余动作。
- `domain_exhausted`与`complete`分别报告域穷尽和最优值是否已确定。候选上限只限制工作，不构成完整域声明。

不缓存“每个世界／牌对分别优化红方技能”的静态矩阵。缓存和回应均绑定同一个冻结的可观察政策；世界间共享技能决策的约束保留。

## 4. 策略生成及认证

`InformationDoubleOracle`循环求受限树解、冻结合法完整策略、检查完整根域回应，再加入新红牌或黑牌。全域下界L使用红方策略在各setup的完整黑方回应下界加权；全域上界U使用黑方完整延伸下的共同红方最优回应上界。各自最强的界和对应策略单独保留，可在同一不可变模型上续跑。

遗漏原质量保留[0,1]贡献。完整类型／行动模型且`U-L<=epsilon`时才标记相应认证；世界采样质量合计1不证明真实后验完整。受限树值单独放在迭代轨迹，不能覆盖全域界。

当已证实的红方保障达到现有全局效用上界时，可以不扫描全部红牌；已知质量全安全而仅缺失世界阻止闭合时，以`unrepresented_mass`停止。此时完整红方最优回应仍可标为未执行，保障来自另一侧的完整检查和原收益范围。

## 5. 已验证缓存特化

红方冻结表**精确为空**时，全部技能决策均采用合法的next-first回退，和已审计的`PublicSkipOptionalPolicy`v2完全相同。`BlackSkipCache`此时复用已有FS完整黑方续演／规则状态缓存，包含每席资源、私密能力记录、当前日和深度配置。它只保存当日0/1的精确值，未知不缓存。

具体类、空表和收益版本共同限定适用范围。非空学习表和子类回退到原生信息集树／序列DP，不将近似政策替换成跳过政策。相同策略下，全部六套控制黑牌的原生信息树值与缓存路径一致，重复检查产生真实命中；非空表没有使用该缓存。未来T1收益不能沿用这项标量特化。

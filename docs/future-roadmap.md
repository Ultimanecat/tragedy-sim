# AI 路线图（2026-10-10 精简版）

本页只保留现状、关键经验和未来任务。历史对弈、源码指纹、逐次修复数字见 [校准报告](ai-cutoff-calibration.md)；接续实现时同时读 [交接文档](codex-handoff.md)。

当前范围：已录入的 FS/BTX，13 个基础剧本、25 个难度版本。新剧本、人工核对和 ECS 部署分别依赖用户资料或授权。AI 入口收敛与共享规划层已实现；矩阵化开始分阶段接入。

## 已完成的关键节点

- 规则引擎、35 张范围内角色、本地／局域网、正式胜负及完整文本 replay 已运行；BTX 一次提交整套初始身份，只公开正确数量。
- 两人局红方共享三席位与三牌联合规划；后端支持原子提交，CLI／模拟保持单步引擎接口。部分出牌后可重新规划余下席位，多人权限没有扩大。
- 公平红方使用身份／剧情、事件当事人、暗牌分维信念，在共同世界批次中评价计划；硬证据可构造补样，终猜独立求合法完整身份 MAP。
- Witness 按规则集组合可复用组件，覆盖多类事件、死亡、能力来源／拒绝和轮回末失败；开发侧已有中文证据变化、三维采样及同根反事实日志。
- 黑方保留定式／搜索基线；联合黑方可使用公开或信念回复模型。Oracle 明／暗牌红方仅用于诊断。
- 最近完整回归为 592 项；前端 25 项、生产构建与 lint 通过。BTX04/08 的强黑方代表局已完成，所审计四局出牌回退为零；这些单种子结果不构成棋力排名。

## 当前问题与必要经验

1. **确定事实与采样频率分开。** 没采到世界不表示世界不可能；12/12 样本相同不自动形成硬结论。候选耗尽先查约束构造和提议覆盖，保留正确硬约束。
2. **信息完整不保证行动正确。** BTX04 后两轮已锁定女学生为自杀当事人、亲友 12/12，仍重复失败。应向更早日期查资源准备、候选覆盖和后续策略，避免直接调高信息奖励。
3. **严格区分时间点。** 关键人物／满足都市阈值的不安定因子死亡可立即失败；亲友在轮回末公开并导致失败；时间旅行者有特殊最终日日末。规则前提和死亡批次必须完整。
4. **同一计划在共同世界中评价。** 防止逐世界挑最优行动的策略融合；单牌历史可能漏掉当日联合攻击。增加世界数无法弥补防御候选缺失。
5. **模拟边界与初始身份明确。** 日末／轮回末模拟不能用 Oracle 终猜答案挽救失败；最终猜测只遍历初始 cast，临时替身及动态获得能力单独处理。
6. **可重复证据不重复放大。** 保留观察来源、时间点和因果族，证据独立于行动节点预算；开发日志默认关闭，不进入玩家界面／SSE。
7. **可信性能对照。** 区分证据、候选、模拟、终猜成本；串行等墙钟与固定工作量分开，记录超时。文本 replay 保留 cast／菜单顺序，开发报告保留对应源码与完整／部分状态。

## 近期实施顺序

### A1. 矩阵化信念（新增，优先）

M1：新增读写边界明确的信念表示，先作为现有求解器的观察／日志投影。

首个切片已实现：身份／当事人硬域与近似概率、身份存在与保守数量上下界、显式 AnyOf 和原始 witness 保留、中文／JSON 开发日志。联合黑方共用身份域计算。暗牌正式矩阵、剧情分布及完整数量传播仍待完成；采样与终猜算法尚未改用矩阵。详见 [矩阵表示与复用](belief-matrix.md)。

重构行为对照：对 `e637156` 的粒子实现，FS01／BTX04 各验证未出牌与已出两牌根节点，固定工作量下动作、计划、世界统计与评分 trace 全等（排除耗时字段）。默认采样与候选算法未改变；此批无新棋力胜率结论。

- 格子用 `hard_status = always | never | unknown`；概率另存为 `approx_probability`，缺乏估计时为 `null`。always／never 表示当前证据下所有合法世界都成立／都不成立，unknown 不表示 0.5。
- 身份矩阵：列为初始角色、行为初始身份；临时替身、病毒转化和因子获得能力另设当前状态层，不覆盖初始身份。
- 事件矩阵：日期／事件 × 角色；暗牌矩阵：当日放置槽 × 牌面，随当天重建，并保留手牌／限次约束。
- 主剧情分布、副剧情存在／数量状态与身份数量分布独立表示；公开的 FS/BTX 规则集不当作隐藏变量。
- 身份存在向量记录硬状态及 `P(N>0)`，同时维护数量上下界，按需维护 `P(N=k)`。矩阵行和是期望人数，通常不等于存在概率；异格的额外身份数量需按规则处理。
- 近似概率注明估计来源和样本规模；粒子未命中及数值接近零不写成 never。当前 MAP 前列代表候选的归一化不能冒充完整后验。

M2：将 witness 编译为可审计的矩阵更新及独立约束。

- 一元事实执行确定／排除／限制候选；依据数量与关系约束做有证明依据的传播。
- 析取保留结构，例如“甲为关键人物或乙为关键人物”；同时可先影响近似概率。该析取本身不排除丙为关键人物，排除需要结合身份数量等额外前提。
- 保留 `AnyOf`、数量、条件式等显式约束及软评分因子；单独保存原始 witness、source、时间点，便于复用与日志追踪。不引入隐式 hook。
- 软 witness 调整支持度／近似概率，不直接写 always／never。跨维度关系仅在实际 witness 需要时表达，完整相关概率模型仍延后。
- 重复观察与多格投影共享同一证据来源，避免把一个析取分别作为多个独立事实重复计分。

M3：接入候选构造、合法世界采样及终猜。

- 从矩阵允许域和数量约束生成组合；独立记录的硬析取在生成／最终 matcher 中执行，不能因矩阵未完整表达而丢弃。
- 矩阵概率用于提议排序和近似权重；材料化后仍检查剧本合法性与完整 witness，保持同计划跨世界评价。
- 最终猜测保持整套合法身份 MAP，不逐列取最大概率。无解显式诊断，不通过放松硬条件或读取真值恢复。
- 先并行保留旧实现作为消融，验证行为，再替换正式路径；不把内部重构长期扩增成新的大厅 AI 模式。

验收：硬状态有推理来源、真值保留；概率归一化／数量语义正确；析取与临时身份反例通过；日志启用不改变固定工作量行动；FS/BTX 旧新同种子对照、候选耗尽及实际耗时有记录。矩阵化本身不视为棋力提升。

### A2. 更早日期的因果与规划审计

- 从 BTX04 第 1—4 天开始，对照信念红方与两种 Oracle；保存相同根、预算、候选、身份／当事人／暗牌信念和后续策略。
- 比较日末／轮回末 horizon，审查限次降不安牌、学生／护士等技能准备、移动保护与主规则防守，区分当前候选缺口和未来动作填充误差。
- 增加完整对局对照；Oracle 终猜读取答案的胜利单独标识，不算行动规划成功。有限候选下开眼失败不构成无解证明。
- 技能使用率作审计；信息收益、重复调查、因果线代价和必要时牺牲一轮统一进入价值／长搜索，不强行提高好感牌使用率。

### A3. 泛化与可信对抗评测

- 先扩展 BTX02/09/11 和共同 seed，再覆盖全部 FS/BTX 标准版、难度配对；保留固定／策略黑方与联合信念黑方。
- 秒级与分钟级分别测；需要最强棋力时另设每步数分钟档。记录整局胜负、失败轮回、终猜数量、真值兼容、回退、实际耗时与超时。
- 分离证据维护和原子模拟的超时来源；每局保存完整 replay 和源码指纹，不将半组报告当完整配对。
- 剩余 witness 按 [覆盖审计](witness-coverage-audit.md)和 [候选清单](witness-candidate-backlog.md)逐项推进，保持正反例、source 消融及因果族封顶。

### A4. 价值校准与黑方改进

- BTX 价值分开预测直接存活、到达终猜及整套猜对，再对齐整局胜率；补足终猜红胜样本，按剧本／seed 留出验证后接入搜索。
- 黑方复用红方公开硬知识下界与近似信念，建模暗牌回应；不把全知红方作为正常假想敌，不提前读取私密调查答案。
- 验证信息泄露项，逐步加入可选能力的顺序／沉默／佯攻及混合策略；保留强制效果的引擎结算。
- 较长 horizon、尾部风险和后续策略升级逐项消融，日末继续作为默认基线。

## AI 模式收敛

实施进度：用户已授权入口收敛与公共组件重构。第一切片提取 `belief_planner.py`：公平观察、世界重建、计划执行、trace 和终猜共用；粒子集成解除对历史 ISMCTS 搜索算法的继承，两种 Oracle 共用世界重建。历史类暂留作开发回归。

入口切片完成：房间注册表统一名称、工厂、规则集与团队权限。可选 ID 从 16 收敛到 12；旧 ISMCTS 三种和历史风险退出房间入口，API 对旧 ID 显式报停用，不静默换算法。联合黑方在大厅按回复模型配置，底层保留两个 ID 供基准区分；单步策略／朴素／优化 MCTS 收入可展开的开发区，两种开眼继续直接可选。算法预算未改变。房间与三牌 API 44 项、前端 25 项和生产构建通过；全量回归末次验收另记。详见 [AI 收敛建议](ai-strategy-consolidation.md)。

主线为粒子红方与三牌联合黑方。旧算法暂保留开发基准／回归，历史风险保留黑方内部回复用途；后续清理无人调用的代码，不能删除基准需要的共享能力。

粒子版现继承公共 `PublicBeliefPlanner`；联合版仍继承策略／优化 MCTS，并使用 RiskAware 回复。继续探索三牌计划缓存、规范命令键、候选评估与共享预算的边界；把公共层里旧路径专用的持续粒子／随机续演依赖逐步下移到历史类。不将双方不同价值函数强行统一。身份域投影已供黑方公开知识复用。

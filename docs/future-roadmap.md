# AI 与后续开发路线图（2026-09-26）

本页只记录**现状、下一步依赖和验收标准**。已完成实验的数字、复现命令与失败轨迹放在 [AI 对弈基准](ai-benchmark-results.md)；现有策略的具体行为放在 [AI 现状](ai-current-state.md)；witness 的信息边界放在 [证据设计](ismcts-witness-design.md)。旧路线图的细节可在 Git 历史中查阅，不再把过期的阶段门槛当作当前任务。

## 当前基线

- 已完成 35 张范围内角色卡、首批 22 个官方剧本（FS 2、BT/BTX 11、MZ 4、MC 5）、本地及局域网游玩。其余剧本需要用户继续提供资料并人工核对；各规则集集中人工试玩仍待做。
- 保留随机、固定策略、朴素／优化／策略 MCTS、公开防守、旧 ISMCTS，以及 FS/BTX 明牌／暗牌 Oracle，作为可选对照。FS/BTX 黑方已有可选的三牌联合搜索；FS/BTX 红方已有基于身份、当事人、暗牌分维信念的三牌粒子集成规划器。
- 粒子集成版现可在 **FS/BTX 两人局的主人公出牌阶段**使用，是单日、有限候选的规划器，不是完整跨日 ISMCTS；BTX 最终猜测已直接按完整身份候选的 witness 权重排序。FS01/FS02 的秒级初测为新版 3/4、旧生存优先版 1/4；分钟档只有 FS01 的一组成对整局，不能据此断定棋力排名。已知薄弱点是 FS02 失败局、BTX witness、跨日资源保留、后验校准和长局耗时。
- BTX 的规则引擎已支持轮回耗尽或提前进入最终猜测：领队一次猜测所有角色的**初始身份**，只公开猜对数量，全部正确才赢。当前 BTX AI 尚未围绕这个终局目标完成红黑双方的专项优化。
- FS/BTX 事件 P0、BTX 因果线正向、恋爱死亡、强制杀人狂首个结果及剧作家能力来源析取 witness 均已组件化，并通过真实引擎正反例。BTX02 新强制路线的 3-seed 消融在固定黑方下有提升；BTX09 能力来源对强黑方的单种子测试出现后验改善、行动结果反向。小样本不能确定棋力排名。

## 下一阶段：先使 BTX 成为可信的对抗基准

### 当前最优先：轮回难度配对基准

卡面多轮回数现已展开成独立的标准 / Easy / Very Easy 剧本 ID；此前所有旧基准读取源 JSON 的最大默认轮回数，
因此实际使用的是 Easy（三级卡则是 Very Easy），不能与较少轮回的标准版混称。先用相同剧本秘密、相同种子、相同
红黑策略和相同墙钟预算做配对矩阵，并在每条结果中固化轮回数与难度。

- 秒级档先覆盖全部 BTX 多难度剧本，报告双方胜率、平均失败轮回、最终猜测正确率和完整对局耗时；标准版与 Easy
  必须按相同种子配对，三级卡同时保留 Very Easy。
- 分钟档复用同一入口，只在秒级结果与失败轨迹稳定后扩大种子；墙钟是每次决策预算，另报实际整局耗时。
- 更多轮回在规则上给予主人公更多信息机会，但有限候选 AI 未必能稳定兑现；验收看总体趋势、逐剧本翻转及置信区间，
  不要求每个随机种子严格单调。异常反向样本必须保留 replay/trace 供 witness 与跨日规划审计。
- 基准入口为 `python -m benchmarks.ai_difficulty_matrix`。完成基线后再依据同一批轨迹推进 BTX witness 和主动调查，
  避免继续针对单一 Easy 剧本调参。

seed 0–4 的首轮低预算矩阵已完成：标准版主人公 13/45、Easy 14/45，配对中 Easy 独有胜局 5、标准版独有胜局 4；
Easy 的失败／可用轮回比例较低，但最终猜测合计正确率反而较低。下一步已从“继续扩总体样本”收窄为定点审计反向样本：
BTX01 seed 2、BTX02 seed 2/4、BTX06 seed 4、BTX09 seed 3。先检查真实世界是否被 witness 错删、粒子是否耗尽／回退、
新增轮回的软证据是否过度改变完整身份排序，以及行动候选是否因随机流漂移；通过正确性审计后才运行分钟档或调整策略。
BTX06 seed 4 已确认真实配置仍通过全部硬 witness，但不在容量 192 的终局随机配置库中；此前 0/9 的直接原因是稀疏联合
MAP，而非粒子耗尽。轮回末 witness 现会把“某角色初始区域已有 2 密谋且随即失败”拆成炸弹主规则压力和“该区域初始角色
中存在魔女”的局部联合压力；炸弹世界的候选器也能定位魔女初始区域。另加入只读取公开目标的地点防守先验：黑方当天在
区域放牌时，候选池保证包含对该区域使用禁止密谋的合法三牌，并在所有存活维度之后给予 0.08 的有界奖励。BTX06 seed 4
的标准 / Easy 定点回归均由重复失败改为仅首轮失败、次轮存活获胜。该先验不是“暗牌必为密谋”的硬推断，也不能覆盖任何
存活率差异；仍需在其他剧本做消融，防止针对 BTX06 过拟合。

独立的终局合法配置求解器已经完成：最终猜测不再直接从行动粒子库挑一套完整身份，而是遍历所有主规则／副规则组合，
对软 witness 中实际涉及的身份约束做小型构造搜索，再把无关的对称身份槽合法补全。选择的是完整配置 MAP，候选总数、行动

### 当前最值得做：可配置的跨日策略 rollout

先不继续手调某一类好感能力，也暂不直接训练神经网络。可配置稳定边界 rollout 的第一切片已经完成：两个已知剧本 Oracle 支持日末／轮回末／整局，公平粒子集成版支持日末／轮回末；根节点仍是三张主人公牌，后续由固定、可复现策略补全，不立即扩大成完整跨日树。粒子版明确禁止按每个隐藏世界的真相选择后续主人公牌或最终猜测。

跨日切片最初只使用真实终局胜负和现有规则集条件估值；首轮固定种子消融显示：Oracle 明牌版在 FS01 有小幅改善，暗牌版持平；公平粒子版在 FS01/FS02/BTX01 没有胜负改善，部分平均失败轮回略增，且耗时约为日末档的 3–4 倍。故 `day` 仍为默认，`loop` 作为实验开关保留。其后只在日末公平规划器加入了严格排在存活之后、基于公共粒子熵和本轮可达性的微量信息值；首轮全 BTX 消融尚未显示额外胜率，不能将其宣传为已证明增强。

公平版现已把**隐藏世界**与**黑方后续策略**拆成两个采样维度：每个身份／事件／暗牌世界动态列出适用的主线、刺杀和事件路线，不依赖剧本编号；同一组三张红方牌逐路线模拟，并以该世界中的最危险路线评分。策略数量可用 `--mastermind-policy-samples` 消融，`1` 严格保留旧随机单路线基线，trace 记录实际世界×策略模拟数。首轮低样本中，FS01 日末档从主人公 1/5 提高到 3/5，BTX01 仍为 2/2；但 FS01 轮回档反从 1/2 降为 0/2且耗时翻倍，显示长 horizon 会放大后续策略误差。因此下一步不是继续无条件增加路线数，而是校准黑方路线概率、补充真正的联合黑方搜索，并在同一墙钟下比较均值、尾部风险与最坏情形聚合；只有长 horizon 稳定优于日末档后，才把它用于学习型 value 标签或扩大成跨日树。

### 1. 红方信念与联合行动推广到 BTX

已把 FS 粒子集成的候选—交叉评估接到 BTX，日末评分不再套用 FS 特有压力项，最终猜测直接排序完整身份分配。11 个已录入 BTX 剧本已完成单种子低预算完整对弈冒烟测试；下一步是 BTX witness 专项审查、更多种子和相同墙钟预算的配对验收。FS01/FS02 保留回归。

- 身份／主规则、每日事件当事人、当前暗牌及剧作家历史出牌倾向继续分维维护；组合时必须是合法完整世界，不能读取真实隐藏剧本或尚未揭示的牌。
- 为 BTX 逐条审查硬 witness：只有所有合法解释都支持的事实才能排除世界。事件判定时的公开阈值快照现已写入公开日志并可跨轮回复用；死亡、规则 X/Y 失败、强制能力的出现或缺席仍需逐项补齐同类快照。可选能力未发动、可自由选择的行动与“看似故意”只更新行为后验，不能硬排除身份。补足 FS 已知的轮回末规则失败 witness 缺口。
- 系统性覆盖矩阵与实施顺序见 [FS / BTX witness 覆盖审计](witness-coverage-audit.md)。每个新增来源均通过 `--disable-witness-source` 做同种子消融；软 witness 按因果链分组封顶，避免把同一现象的多条日志重复当作独立证据。
- Witness 已改为按规则集显式组合的组件注册表；复用和扩展约束见 [Witness 组件架构](witness-components.md)。后续迁移 MZ/MC 时先建立各自组件清单，只复用规则前提完全相同的公共组件。
- 最终猜测按**整套合法初始身份分配的后验概率**决策，而非逐角色最大边际拼接；已修正“病毒使普通人临时变成杀人狂后，公开当前身份却误锁初始身份”的反例。全部 11 个已录入 BTX 剧本现有逐结算点回归，保证真实世界不被硬 witness 误删；契约、定时炸弹和时间旅行者最终日能力已用局部联合软因子保留因果关联。继续测试正确人数分布、更多实际行动轨迹、轮回间证据继承，以及提前猜测是否值得。证据维护独立于行动节点预算，但总墙钟仍计时。
- 三张红方牌继续作为一个候选，跨同一批可能世界比较；好感／身份能力和事件选择若会决定成败，应纳入搜索或明确标注当前回退策略。随后解决跨日限次牌保存与事件截止，不能只最大化当日存活。
- 好感能力的声明／接受／拒绝／无效果现已写入结构化事件和基准汇总，被拒绝的能力也会生成公开身份 witness。**能力发动率只用于审计，不是优化目标**：当前微量奖励不是固定抬高友好牌，而是按公共粒子熵、最低轮回、剩余日期／友好牌、合法目标、已知事实和一次性使用状态估算可兑现信息；总奖励封顶且不能覆盖任何存活差异。首轮消融无额外胜率，故不继续抬权重。重复调查边际收益以及“牺牲一轮换决定性证据”仍留给更长搜索或学习型估值器。详见 [信息价值设计](information-value-design.md)。

**验收：** 构造因果反例和公开／私密信息隔离测试；每个 BTX 试点剧本都有终局猜测回归和失败轨迹；FS 基线不得无解释退化。先做到正确、可复现，再评价胜率。

### 2. 黑方从“制造轮回失败”转向“赢得整局”

FS 黑方三牌联合搜索仍可作行动候选器，但 BTX 的效用必须覆盖红方存活、继续轮回、提前猜测及最终猜测。黑方即使成功制造失败，也可能因暴露身份而输掉整局；反过来，隐瞒技能可能牺牲当前收益。优先用真实终局胜负评价，不把“少透露信息”直接当作固定分数奖励；短搜索需要截断时，信息泄露惩罚只能作为可校准、可消融的近似值。

回复模型分层推进：`public` 只用公开局面与暗牌目标驱动固定策略，是低成本基线；`hidden` / `full` 是全知诊断上界。BTX 试验性 `belief` 已复用红方 witness 编译器与分维粒子，针对同一黑方三牌采样多个红方联合回应，由黑方根节点 UCB 把更多模拟分给有潜力的计划。模拟红方接收公开观察，以及从已结算查身份事件中黑方必然能推断的私密答案；不能从能力申请、拒绝或尚未结算的事件提前读取答案。同身份群等关系式私密知识和历史旧日志仍保守忽略。终猜边界已有实际 MAP 猜测评分；根节点搜索仍缺跨日信息集树和经真实胜负校准的早期终猜估值。后续升级为观察节点上的 MCTS／对抗搜索时，要避免按真实世界逐粒子替红方选择动作的策略融合，也不能在最终猜测处直接提交真值答案。

- 黑方第一版只维护红方的**确定性知识下界**：使用双方已知的固定规则和红方必然观察到的现象，运行与红方共用的硬 witness，求出红方不可能再相信的身份整套分配。推理规则本身是公开的；但具体结算是否公开、私密调查是否发生及其结果，仍须按红方实际可见信息判断。黑方知道真实剧本，可以推断一次已知调查会告诉红方什么，却不能把尚未到达红方的信息放进模型；也不预设红方一定完成了所有软推理。
- 在知识下界之上，以少量粗粒度红方策略模型预测联合防守、调查偏好和最终猜测（例如重视当日生存、保护已确定关键人物、倾向追查可疑目标），而不先求精确的嵌套后验。测试时混入更强、更弱及不同风格的红方，并检查黑方对未知红方知识的乐观假设是否导致过度暴露，避免只针对一种 AI 伪装。
- 黑方候选覆盖直接达成失败路线、分散威胁、佯攻、目标／牌面混合，以及**合法可选**的技能发动或不发动、发动顺序。区分必须触发的能力与可选能力；无法控制的公开效果不能被搜索器当作可隐藏。沉默本身也可能被红方视为软证据。
- 对同一黑方计划评估红方可能的防守、后续观察更新和最终猜测概率。既要防止“真实剧本泄漏给模拟红方”，也要防止只针对某一个采样身份采取只有全知红方才会采取的行动（策略融合）。从短剧本的整局模拟／反事实比较做起，再扩展到跨轮回树搜索与混合策略。

**验收：** 在同一预算下比较“只追求当前失败”与“考虑红方确定性知识及行动预测”的黑方；记录黑方整局胜率、红方最终猜对人数分布、提前猜测次数、知识下界排除的身份数与能力发动率。做关闭伪装／关闭逆向建模的消融，并逐局检查是否只是牺牲可赢局换取表面低泄漏；更细的红方软后验留待粗模型确有不足时再加入。

### 3. 对弈、性能与可信度

- FS01/FS02 先扩大成对种子，重点诊断 FS02 seed 0；BTX 先短剧本、后 11 个剧本。红黑双方固定同一剧本、种子和席位条件，保留旧策略为对照。
- 至少设秒级与分钟级两档**每次决策墙钟上限**，记录实际思考时间、证据维护／模拟开销、整局耗时和胜率置信区间；不要用节点数代替等时间比较，也不要从小样本或小预算外推大预算棋力。超大预算只在分钟档显示价值后用于剧本平衡性研究。
- 建立小局面穷举／高预算参考值，量化红方候选漏掉“可存活三牌”的频率；用完整终局样本校准截断估值。任何新策略都跑规则正确性、信息隔离、固定种子对弈和消融测试，再与基线比较并单独提交。

首批 BTX 联合 witness 已完成 seed 0–4 的开启／关闭消融：两组主人公均为 28/55，没有总体胜率差异，局部最终猜测有增有减。消融期间发现并修复了“局外人额外身份槽”未进入约束采样的问题；BTX08/BTX11 已替换重跑。终局 trace 现保留权重最高的完整规则／身份候选；由此又修正了日末死亡只承认初始杀人狂、忽略病毒临时转化，以及死亡失败忽略因子临时关键人物能力的问题。BTX08 当前主要混淆真实 `unknown/factor` 与公开轨迹无法区分的另一组规则 X／身份，BTX01 仍有低正确数。近期不再凭单种子手调权重；下一步让跨日规划显式评价可执行的主动调查，再决定是否需要新 witness。

## 保留但延后的工作

1. **真正跨日／跨轮回搜索与统一价值。** 单日规划不足以判断限次牌、未来事件、控制不安、好感能力、故意失败换取最后一条决定性证据及提前最终猜测。短期不单独手调“信息奖励”；先扩展稳定时间点和终局采样，再以整局胜率学习或校准统一价值。后续可并行比较可解释的启发式估值、强化学习 value head／策略网络及二者混合，能力发动统计只负责发现策略偏差。
2. **扩大跨维度信念关联。** 身份、当事人、暗牌主体仍分开；BTX 的契约／定时炸弹已加入首批局部“主规则×身份”软因子。后续只在出现独立维度无法表达的合法因果案例时继续增加，不直接退回巨大联合粒子。
3. **黑方行动空间与混合策略。** 合法组合不能因模板而永久剪掉；候选覆盖、等价去重、策略多样性和对不同红方的稳健性仍需验证。FS 联合黑方目前不等于稳定最优。
4. **其余规则集与多人红方 AI。** BTX 通过后，再逐个规则集扩展 witness、结算选择与搜索；三名主人公各自决策另作信息／协调问题，不混入两人团队 AI 的验收。
5. **官方剧本与人工试玩。** 新剧本依赖用户提供资料；已录入剧本需逐批人工核对与完整试玩。远程联机／ECS 需要云实例及部署授权，当前只保留局域网，不与 AI 主线并行实施。
6. **学习型估值器。** 在规则引擎、公开信息状态编码和自对弈数据格式稳定后，建立可复现的数据集与评测集；先训练只预测整局胜负的 value 模型，再考虑策略先验和强化学习。输入必须遵守座位信息边界，并与手写估值做相同预算消融，避免神经网络借由隐藏字段作弊。

## 实施边界

AI 只通过规则引擎的结构化行动与合法状态转移模拟；红方决策只能消费其席位可见的 Observation。搜索 Trace 和后验诊断只留在服务端调试／基准，不进入对手视图或 replay。每个切片保持现有模式可用，测试与基准结果分开记录；本路线图是优先级，不承诺某个 AI 必胜或 BTX 的理论平衡结果。

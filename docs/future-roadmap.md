## 接下来按顺序推进

### 1. 终猜联合概率与审计

- 当前压缩 MAP 保留代表，未累计完整后验质量；`compatible_count` 是传播支持外界，top 候选不能作为概率分母。
- 对完整身份表 G，汇总所有同身份表／不同剧情的后验质量，再除以全部合法世界质量。不能相乘角色边际。
- 小空间独立枚举验证归一化、同表跨剧情汇总及最优猜测；大空间加权计数／重要性估计记录误差和 ESS。明确是当前信念模型概率，先验／软似然尚未校准。
- 先作诊断，随后单独消融终猜策略和预计整套猜对概率估值；不与其他规划变化同时调参。
- 用户新增逐步 debug 日志：每次 witness 变化、行动判定／效果结算及 AI 决策记录概率前后值、delta、原猜测概率和推荐切换，复用现有审计组件。默认关闭，独立诊断 RNG／计时与玩家信息隔离；用于审计黑方泄露／伪装，先记录再单独接入黑方评价。详细字段、批次归因及误差要求见 [设计计划](final-guess-probability-audit.md)，待实现。

### 2. 防御候选与短跨日规划

- 优先 FS-02G、BTX04、BTX06 的重复失败：先查采样危险是否覆盖，再查联合防御是否进入候选、同批次评分与更早准备。
- 移动保护、地点禁止密谋、降不安、限次牌保留与好感准备都要检查；增加世界数不能补出未生成的行动。
- 保留日末基线，短跨日／轮回档分别消融；后续廉价策略的误差单列。公开防守与开眼续演差异用于诊断，开眼终猜胜不算行动防御成功。
- 危险分层、近分行动共同批次复评及有限世界覆盖保留；任何提议改动都记录 q，禁止定向添世界后不校正概率。
- 验收：共同根解释清楚，同源码多 seed、标准／Easy 和留出剧本仍有效；不按剧本 ID 调权。

### 3. 信息收益与更可信的黑方

- 区分直接存活、到达终猜和整套猜对；调查重复／目标已知时零额外收益，拒绝也产生合法 witness，因果线跨轮回代价保留。
- 不硬性提升信息能力使用率；次数只作审计，降不安和防御能力同样重要。牺牲一轮换决定性信息留给可靠跨轮回规划。
- 黑方从公开确定知识下界和红方近似信念估计暗牌回应，完善沉默、佯攻、可选能力顺序和混合策略。当前回复基线的升级单独对弈，终猜联合成功概率用于检验信息隐藏是否对齐胜负。
- 当前私密查询返回运行时身份；病毒下的历史查询答案重建尚未完整实现，黑方采用保守知识下界。

### 4. 评测覆盖与一个新规则集

- 扩展当前矩阵默认版的其他 seed／已录入 FS、BTX 标准及 Easy；社区 BTX-41 作 11 角色压力案例。秒级、分钟级分别串行报告，超大预算按需。
- 公开规划可靠后先选 MC 简单剧本：开眼诊断 → 逐条 witness／矩阵前提 → 公平规划。已有 MC／MZ 剧本足够启动，补录按缺失机制安排。
- MZ 跨轮回动态身份单独建模；BTX+／MZ+ 规则已接入，公平 AI 仍须专门支持，见 [十周年规则](tenth-anniversary-expansion.md)。
- 人工剧本核对／试玩、额外规则集与远程 ECS 独立推进，当前联机保持局域网；不实现旧 HS／AH、OF、UP 主和仙人。

## 必须保持的边界与经验

1. always／never 来自逻辑约束，12/12 不自动 always，未采到不自动 never；析取与原始 witness 保留，完整 matcher 不可省略。
2. 同一联合计划在共同世界上评价，禁止逐世界选择最优再平均。概率模型、提议、行动奖励和后续策略分别消融。
3. 初始身份、当前身份与能力来源区分；强制能力同一时点同时触发，可选能力由控制方排序。日末失败与轮回末失败不能混用。
4. 公平 AI 只读合法视图和自己收到的私密答案；开发真值／内部信念／Trace 不进入玩家界面或 SSE。
5. 证据维护独立于行动节点和行动墙钟，分记准备、候选、模拟、终猜及整局耗时。软截止有原子超限，不承诺端到端一秒。
6. 按真实运行句柄和完整报告确认任务状态，观察超时不重启；源码／剧本顺序／预算冻结，未完成配对不作胜率结论。
7. 每阶段验证后提交并推送；保留用户附件，`references/` 忽略，不强制提交原始报告。

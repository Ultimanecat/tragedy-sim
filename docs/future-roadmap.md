# AI 路线图（2026-10-16）

本页只维护现状、实施顺序和验收标准。算法推导与接口契约读 [联合行动博弈内核设计](certified-day-game-design.md)，接续开发读 [交接说明](codex-handoff.md)，旧实验读 [历史归档](archive/README.md)。

## 当前状态

- 主线：公平粒子红方＋三牌联合黑方；默认保留prior矩阵提议、合法联合当事人、IID行动抽样、sampled暗牌和legacy候选。开眼基准保留明确标注，实验配置不自动切换大厅入口。
- 证据、矩阵、终猜联合概率、三牌接口和replay已可用。最近代码回归907项通过；联合候选、边缘覆盖、残差抽样的实现与对照已完成，尚无稳定整体提升证据，结果见归档。
- 已确认缺口：单因素黑牌探测会保留其他保护性黑牌，漏掉两槽联合攻击；轻量模型和真实引擎已能识别给定反例。下一步先建立完整联合对抗基准，见 [因果复查](joint-dark-probe-miss.md)。

## 主线实施顺序

以下均为待实现；当前下一项为T0.1。详细步骤、证明范围和论文统一维护在算法设计稿。

| 阶段 | 交付与验收重点 |
| --- | --- |
| T0.1 精确基准 | 单个FS已知世界、未知黑牌根；完整合法三牌及日末能力树，判定是否有保证存活方案，保留穷举裁判。 |
| T0.2 无损压缩 | 局部效果程序、规则／信息双key、资源与观察分支缓存；逐组合对照引擎，未知机制回退。 |
| T0.3 混合策略 | 按需收益矩阵、Double Oracle与全域最优回应；输出L/U/gap和数值误差，超时不宣称最优。 |
| T0.4 公平迁移 | 共同红方策略、按世界分块的黑方回应、原后验质量及信息集约束；有限世界／固定续演与完整模型分别标注。 |
| T1 续局价值 | 从第一版预留规则状态、授权观察、信念与资源接口；日末评价整局获胜价值，一次求解中冻结估值及更新模型。 |
| T2 有限跨日 | 先2日再3日，按可见观察更新witness／信念并递归；同信息集共用续招，单独衡量叶值误差与成本。 |
| T3 跨轮回 | 轮回失败进入保留知识的下一轮；真实整局终结才置0/1，支持有依据的风险／换信息取舍。 |

最终优化整局获胜概率。当日存活保留独立基准；长期模式不固定让它压倒全部未来收益，不硬抬信息技能使用率。近似续局价值只支持给定模型内的最优性结论。

## 后续与独立方向

- 战术内核可靠后共享给实战黑方；按红方公开确定知识／近似信念建模，独立评测出题、混合策略及终猜信息隐藏。
- 后验／witness持续回归；较大行动样本、完整小支持加权、跨维关联、单witness归因与病毒历史查询重建按需独立实验。
- 先覆盖已录入FS／BTX标准、Easy及BTX-41压力案例；再从MC简单剧本做开眼基准→witness／矩阵→公平规划。MZ动态身份、BTX+／MZ+需专门验收。
- 完整整局信息集树、三／四人独立红方、强化学习／神经估值及高预算平衡评测延后；人工剧本／试玩、前端及远程ECS见 [Web／联机计划](web-and-lan-roadmap.md)。当前联机保持局域网，范围排除旧HS／AH、OF、UP主和仙人。

## 验收纪律

1. 公平AI只读授权观察；相同信息集共用决策。黑牌预先提交，揭牌后能力才可回应实际红牌。
2. 后验质量、攻击压力分支、行动奖励分离；未采到不等于never，样本全是也不等于always。保留析取与完整matcher。
3. 所有候选在共同世界／攻击集评价；限次牌所有者、身份变化、时点与观察差异均须保留，启发式风险不作安全证明。
4. 小样本找bug；策略对照默认4进程、固定seed0–9、固定工作量，标准／Easy和留出剧本分报。性能空闲串行校准，续跑不重复计样本，见 [实验方法](ai-experiment-protocol.md)。
5. 分别比较当日／续局值／跨日／跨轮回；主指标整局胜率，辅以行动胜、终猜、重复失败、有效信息、资源和耗时。记录完整性、horizon、效用版本及认证范围。
6. 证据预算独立于行动；内部世界／Trace不进入玩家界面或SSE。每阶段验证后提交推送，保留用户附件，`references/`继续忽略。

规则集扩展用 [AI调优指南](ai-tuning-guide.md)、[witness覆盖审计](witness-coverage-audit.md)和 [候选清单](witness-candidate-backlog.md)。历史源码、实验数字和旧优先级已归档，不作为当前待办。

# 小型身份支持集的行动抽样（2026-10-16）

## 已确认的问题

FS01、marginal_guard、seed0、第2轮第4天，精确后验包含4套完整身份表，各质量.25；职员杀手边际.25。4个IID行动世界全部给职员传谣者，所有候选被估成全存活，真实局面随后被杀手自身密谋阈值击败。矩阵及硬证据没有排除真相，遗漏发生在行动世界抽取。

对同一授权根独立检查：4套身份分别兼容全部30套合法当事人配置；144个角色×当事人原始组合中120个合法，其余24个仅因当事人重复限制不合法。所有合法组合通过完整硬matcher。诊断只在推断完成后查询真值，不向公平策略传入真实身份。

## 可选方案与概率边界

残差抽样先分配 `floor(N*p_i)` 个副本，剩余副本按 `N*p_i-floor(N*p_i)` 随机抽取，最后随机打乱。副本数期望为 `N*p_i`，零概率不产生副本；4套等概率身份、4个行动样本时，每套恰好一个。

这属于降低重采样方差，有限样本的非均匀质量仍有随机误差。它不等于把所有身份无条件改成等概率，也不等于完整后验的精确加权积分；尾部风险及“所有抽样世界都安全”等非线性量仍是近似。若需要保证小概率身份也必定覆盖，应另实现显式质量的完整支持集规划，并统一存活、状态、信息和尾部评分的权重。

原型只在以下条件满足时启用：身份池有完整精确枚举证明、支持数不超过行动样本数、使用合法联合当事人、有限枚举证实每个身份与每个正质量合法当事人配置均能materialize且通过完整matcher。枚举上界2048，超限或有角色相关拒绝就回退IID，不消耗该抽样步骤的RNG。未知支持、截断矩阵提议池和分区诊断样本不能声称完整。

当事人仍按原联合后验独立抽取，暗牌仍按原策略抽取，后验、witness和终猜不变。认证避免“先强制角色配额，再拒绝不合法当事人”带来的角色条件质量偏差。原型只改实际公平红方；黑方内部回复模型保持原样。

## 退化审计：身份覆盖后仍有联合暗牌遗漏

FS01 seed2，第2轮第2天，残差版覆盖4套身份各一次，女学生关键人物／巫女杀人狂均4/4；4个当事人样本中也有“当天谋杀由职员引发”。所选`fi女学生＋h职员＋v巫女`在96个额外边缘攻击分支及既有技能路线下仍被评为4/4存活。

固定该授权根及其原4个角色／当事人样本，决定完成后枚举合法三张暗牌：其中一个世界的首个合法组合`d女学生＋fg职员＋fp医生`已在`incident_pressure`路线确认主人公失败，而该世界的全部marginal_guard分支没有失败。其他3个世界各504套均未找到失败；有反例的世界在首个失败时停止，未冒称完成全部4×504穷举。

这次退化具有明确的攻击覆盖缺口，角色完整覆盖仍不能补足联合暗牌遗漏。下一步优先把已有开眼的候选条件化反例组件迁移到公平规划：每个原角色／当事人组内添加经引擎确认的攻击，所有候选在共同更新后的攻击集复评，组质量保持不变。新增攻击不得写入witness或当作后验抽样。跨日与当事人方差仍保留独立审计。

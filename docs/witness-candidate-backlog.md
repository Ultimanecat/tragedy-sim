# Witness 候选清单与消融顺序

本表是**待验证的推断假设**，不是已实现规则。近期范围为 FS / BTX；候选来自当前引擎的公开事件、两套规则集的事件表和[现有覆盖审计](witness-coverage-audit.md)。尤其不能把其它规则集才有的「自白、毒气扩散、恶意谣言、曝光」当作 FS/BTX 近期任务。以下“硬候选”只表示值得尝试证明；只要存在一个合法反例，就必须降为软证据或放弃。

表中的优先级：**P0**＝公开现象明确、预计能显著缩小候选且测试成本低；**P1**＝有价值但需重建时间点或联合维度；**P2**＝复杂或对在局决策收益有限。组件名仅为建议，实际 `source` 名在实现和消融时固定。

## 对照 FS / BTX 规则速查表逐条核对

核对依据是本地 [FS 规则速查表](../resources/rulebooks/0b2d84f17c995d604bf04e818f20af880a5e5a4d388d87450e5969933f33a90b.png) 与 [BTX 规则速查表](../resources/rulebooks/52184bc7f3f57b2166130ecfe1d3579412161208d72faff5f1164fab99a4bf64.png)，再与 `catalog.py`、FS/BTX 的 `plots.py` 和 `rulesets/common/` 的结算实现交叉检查。这里逐条覆盖**主/副规则、隐藏身份能力和两套事件表**；35 张独立角色卡的好感能力不是同一张速查表，需另做逐卡审计。标记“已有”仅指已有对应证据或合法世界约束，不保证 AI 利用率高。

| FS/BTX | 谋杀计划 | 无额外公开效果；关键人物、杀手、主谋的身份能力分别在下表审计。不能凭“没有看到主规则动作”推断它不存在。 |

| FS | 守护此地 | 学校密谋 ≥2 是公开失败条件；已有正常失败硬解释与学校压力软线索，无新独立 witness。 |
| FS | 开膛者的魔影 | 仅限制剧本身份构成；杀人狂日末能力另见身份表，无独立公开效果。 |
| FS/BTX | 流言四起 | 剧作家能力阶段可给版图密谋 +1；尚无阶段动作的“主谋或本副规则”联合 witness，见 B 类。 |
| FS | 最黑暗的剧本 | 剧本制作时可额外放入暴徒；属于剧本合法性/身份槽约束，不从实际拒绝次数推断该规则。 |

| BTX | 和我签订契约吧！ | 关键人物需少女属性，且其密谋 ≥2 才导致轮回末失败；现有联合解释，不能只凭某少女密谋高就硬定主规则。 |
| BTX | 改变未来 | 本轮蝴蝶效应**发生**即可在轮回末失败，不要求效果有效；已有事件状态和失败解释。 |
| BTX | 巨大定时炸弹 X | 魔女**初始**版图密谋 ≥2；已有联合解释，不能用当前所在版图替代初始版图。 |
| BTX | 好友圈 | 副规则本身无追加操作；两名亲友的身份槽与亲友死亡公开已覆盖，不能把同一死亡算两份软证据。 |
| BTX | 恋爱风景线 | 副规则本身无阶段动作；心上人/求爱者的死亡后不安 +6 与日末杀主人公能力仍可补联合证据，见 B 类。 |
| BTX | 潜伏的杀人狂 | 仅身份构成；杀人狂与亲友能力沿用各自结算，不能凭“没有死亡”排除该规则。 |
| BTX | 妄想扩大病毒 | 活着的普通人不安达 3 才转杀人狂；身份公开与阈值的正反硬线索已有，日末死亡的跨维联合仍待补。 |
| BTX | 因果线 | 上轮结束时**有好感**的角色含尸体，在新轮开始得不安 +2；尚无跨轮证据，见 C 类。 |
| BTX | 未知因子 χ | 副规则本身无直接放牌；因子在学校/都市密谋阈值下分别获得传谣/关键人物能力。即时死亡有联合解释，其它效果待审。 |

| FS/BTX | 杀手 | 日末可杀同区域密谋 ≥2 的关键人物，或自身密谋 ≥4 时杀主人公；后者已有“杀手/求爱者”联合路线，前者需按时间点继续审计。 |

| FS/BTX | 邪教徒 | 强制拒绝好感，可在行动结算阶段无效化禁止密谋；接受/拒绝与实际忽略禁牌已有 witness。 |
| FS/BTX | 传谣人 | 剧作家能力阶段给同区域角色不安 +1；尚无阶段动作析取证据，需容纳医生与 BTX 因子。 |

| FS/BTX | 暴徒 | 可选择拒绝好感；实际拒绝只说明其落在可拒绝身份集合，接受不排除暴徒。 |
| FS/BTX | 亲友 | 死亡在轮回末公开身份并失败；公开身份已有硬证据，死亡前的失败因果只能作为与主规则并列的可能解释。 |
| BTX | 时间旅行者 | 死亡不发生、禁止好感无效、最终日日末低好感可选宣布失败；三类实际发生的现象已有硬 witness，**不发动**不能反推没有该身份。 |
| BTX | 魔女 | 必定拒绝可拒绝的好感能力；炸弹主规则检查其初始版图。接受排除与炸弹联合解释已有。 |

| BTX | 不安定因子 | 学校密谋 ≥2 得传谣能力、都市密谋 ≥2 得关键人物能力，但初始身份不变；证据必须保留“原身份或因子”析取。 |
| FS/BTX | 普通人 | 无专属主动能力；BTX 病毒可临时转化。不能因“不见能力”硬推普通人。 |

### 事件表

| 适用 | 事件 | witness 核对结果 |
| --- | --- | --- |
| FS/BTX | 谋杀 | 当事人同区域选另一人死亡；当前已有实际死亡/被防止/替死的区域候选。无合法目标时不能从未死亡反推当事人。 |
| FS/BTX | 不安扩散 | 任意一人不安 +2，再给**另一人**密谋 +1；目标可选，不由当事人位置决定，目前只有发生阈值 witness，暂不新增当事人线索。 |
| FS/BTX | 自杀 | 当事人死亡；已有死者＝当事人，死亡被护卫或不死能力阻止时还有可补的精确线索，见 A 类。 |
| FS/BTX | 医院事故 | 医院密谋 1 使医院角色死亡，密谋 2 还杀主人公；效果由公开版图决定，不透露当事人位置，目前发生阈值已覆盖。 |
| FS/BTX | 远距离杀人 | 可杀任一密谋 ≥2 的角色，**不要求同区域**；不能复用谋杀的区域 witness。 |
| FS/BTX | 失踪 | 移动当事人，再在其所在版图放密谋；成功移动时已有精确当事人，移动受阻时可研究版图约束，见 A 类。 |
| FS/BTX | 散播 | 任意一人友好 -2，另一人友好 +2；目标可选，不由当事人位置决定，暂不新增当事人线索。 |
| BTX | 邪气污染 | 神社密谋 +2；公开效果不额外识别当事人，发生阈值 witness 已覆盖。 |
| BTX | 蝴蝶效应 | 从与当事人同区域的角色中选一人放计数物；已有目标区域候选，但若无合法效果也依然算事件发生，改变未来会在轮回末生效。 |

以上事件共同适用公开的发生阈值快照；黑猫和教主的特殊效果另见 A 类。**本轮对照后，事件类真正值得优先补的是自杀被防止、教主双重效果和黑猫有效事件；不能把所有效果日志都强行转成当事人身份。**

## A. 事件当事人：从实际效果反推

| 优先级 | 适用 | 公开现象 → 候选结论 | 候选强度 | 必须排除的反例 / 需要的记录 |
| --- | --- | --- | --- | --- |
| P0 | FS/BTX | 自杀发生，随后对某角色出现 `death_prevented` 或 `guard_spent` → 该角色是当日当事人。补足现有“确实死亡才识别”的空缺。 | 硬 | 只在同一事件的效果段内归因；侍从替死应看 `death_replaced.protected` 的原目标，不能把侍从当作当事人；教主效果重复时去重。建议扩充 `common.suicide_victim`。 |
| P0 | FS/BTX | `incident_effect_doubled` 明确发生 → 当日当事人是教主。 | 硬 | 只认事件的公开日志，不从“效果似乎出现两次”猜测；需确认该日志不会由模拟事件混入预定事件。建议独立 `common.guru_incident`。 |
| P0 | FS/BTX | 事件已发生且 `incident_ended.effective=True` → 当日当事人不可能是黑猫。 | 硬候选 | 黑猫作为当事人按规则不产生效果；要核对 `effective` 是否也会被无关的连锁效果或模拟事件置为真。用真实引擎构造黑猫反例后才升硬。 |
| P1 | FS/BTX | 失踪发生、移动被阻止，但事件随后在某版图放置密谋 → 当事人当时位于该版图。 | 硬候选 | 必须把这次密谋与 `missing_intrigue` 关联；版图内多个角色仍保留，不得凭密谋指向某个人；已有成功移动时的精确 witness 不重复计分。 |
| P1 | FS/BTX | 事件已发生却 `effective=False` → 黑猫解释更可信。 | 软 | 谋杀/远距离杀人没有合法目标、死亡被防止、移动受阻等也可能无效果；需要按事件类型计算“正常当事人也会无效果”的概率，不能硬指定黑猫。 |
| P2 | FS/BTX | 不安扩散、散播、医院事故、远距离杀人、邪气污染等效果的目标或计数变化。 | 先审计，未承诺新增 | 多数目标由剧作家任选或由公开版图决定，未必额外识别当事人。只有证明比现有“事件发生＋阈值快照”多出隐藏约束时才写组件。 |

| --- | --- | --- | --- | --- |

| P1 | BTX | 日末单独相处死亡，已排除杀手杀关键人物、打工仔自毁及其它死亡来源 → 唯一同伴为初始杀人狂，或为病毒转化的普通人。 | 析取硬候选 | 现有 BTX 主要为软线索；病毒阈值必须按本轮存活时的历史判断。大人物领地可跨自身所在版图发动，不能仅凭死者所在版图人数推断；两名杀人狂同时发动也必须保留。 |

## D. 轮回末、负观察与行为后验

| 优先级 | 适用 | 公开现象 → 候选结论 | 候选强度 | 必须排除的反例 / 需要的记录 |
| --- | --- | --- | --- | --- |
| P1 | FS/BTX | 正常轮回末失败，完整公开棋盘仅允许某一条主规则失败路线 → 主规则/相关身份候选进一步收缩。 | 硬候选 | 现有 `public_normal_loop_end_loss` 已检查“至少一条路线能解释”；新组件应只补其遗漏的时序和联合角色条件，不要把同一失败再作为独立软分数叠加。 |
| P2 | FS/BTX | 正常轮回末**没有**失败 → 当时会触发失败的主规则世界不成立。 | 硬但低实战价值 | 这通常已经是对局终局，主要用于正确性/离线标注；不能从中推断剧作家“本可选择却没发动”的能力。 |
| P2 | FS/BTX | 剧作家多轮反复对某角色/版图使用同类暗牌，或多次保留可选能力不发动 → 相应身份/主规则路线的概率变化。 | 软行为模型，**非规则硬 witness** | 剧作家可伪装、放空牌、混合策略；应放在单独的暗牌/策略后验维度，按同一因果链封顶并做校准。不能侵占行动搜索预算。 |

## 暂不写成 witness 的现象

- “没有发动时间旅行者能力”不能排除时间旅行者：能力可选；最终日日末**实际宣布失败**的专用时间点已由现有硬 witness 覆盖。
- “剧作家没有在某处放密谋”不能排除任何需要密谋的主规则；这是策略选择，不是规则不可能。
- 远距离杀人的死者可以由剧作家从密谋达标者中选取，不要求与当事人同版图；不能复用谋杀的位置约束。
- 其它规则集与 FS/BTX 同名的事件也可能有不同阈值、替代当事人或效果；在各自规则审计前，不注册这里的 `common.*` 组件。

## 实施与消融

1. 先做 A 类三个 P0：自杀受阻目标、教主双重效果、黑猫有效事件。每个 `source` 单独开关；同一事件的状态、效果、结束日志按一条因果链分组，防止软证据重复计分。
2. 再做因果线的**正向**跨轮回线索。负向线索要等轮初完整窗口标志或等价快照确认后再做；不要用“日志中没看到”构造硬证据。
3. 随后做剧作家能力阶段的析取约束、BTX 恋爱配对与杀人狂路线。这批需要联合身份/副规则世界，先证明匹配器不会误删真实剧本，再观察候选粒子耗尽率。
4. 每批先有正例、合法反例、旧日志缺失字段、真实剧本硬兼容测试；然后以**相同剧本、种子、红黑 AI、预算**比较开启、逐 source 关闭与整组件关闭。先秒级多种子，出现稳定信号才增加分钟级预算。
5. 报告发生频率、硬候选保留量、身份/当事人/暗牌各维后验、最终猜对数、主人公胜率、反向样本、墙钟与真实世界被误删次数。罕见线索即使有效，少量对局的胜率也可能完全不变，应优先看构造局面的候选缩减与真实世界保留。

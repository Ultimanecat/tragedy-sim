# 引擎与规则层审查

## 审查范围

本次审查覆盖规则执行主链：

- `tragedy_sim/engine.py`、`game.py`、`cards.py`、`catalog.py`、`flow.py`、`scenario.py`、`scenario_library.py`、`model.py`；
- `tragedy_sim/phases/**`、`tragedy_sim/effects/**`、`effect_resolver.py`；
- `tragedy_sim/rulesets/**`，包括 `fs/`、`btx/`、`common/`、`legacy/`、`extensions/anniversary.py`、`registry.py`、`base.py`、`scenario_roles.py`、`characters.py`；
- `tragedy_sim/witness.py`、`witness_types.py`、`witness_components.py`、`witness_rules/**`；
- `tragedy_sim/domain/**` 中与规则注册、效果、阶段、状态相关的契约。

验证方式：逐文件阅读并交叉核对调用点；运行定向测试 `tests/test_ruleset_migration.py`、`tests/test_anniversary.py`（33 项通过）；用一次性脚本验证 `loop_options` 展开、`role_slots` 校验、从者/手下初始区域投影、幻想版图回声计数四个边界。未修改任何源码。

## 存疑待确认

以下内容缺少规则书或设计文档的明确依据，本次只记录观察，不下结论。WM 的“旧日魔术”在生产代码中只有三种固定效果（`legacy/cycle.py:102-108`、`301-312`），`wm.cast_spell` 只存在于测试与 roadmap；需要确认官方规则是否允许主人公在多个法术间选择。`anniversary._count` 对 MZ+ 套用了希望/绝望修正（`extensions/anniversary.py:34-42`），MZ 原版 `legacy/roles.py:134-145` 不做该修正，需要确认十周年扩展是否统一按此处理。`role_slots` 在 FS/BTX 是否属于合法输入，代码当前接受但规则层未覆盖部分身份。`legacy/knowledge.py:43` 的 `truthful` 参数在生产与测试中从未以 True 调用，需要确认是否缺少“如实公开忍者身份”的入口。`rulesets/common/projection.py:28` 的 `**{}` 与 `legacy/projection.py:71-76` 的 HSA 版图字段说明公开日程结构曾在两个实现间分叉，需要确认 FS/BTX 是否确实不需要版图字段。`RulesetWitnessCompiler.modules`（`witness.py:58`）没有被读取，BTX+/MZ+ 走 `components_for` 返回空 witness，需要确认这是有意的能力边界。`Game._current_loop_days` 恒定返回 `scenario["days"]`，需要确认是否计划支持分轮天数。最后，侍从随行是否应当无条件移动、幻想版图回声是否应计入“同一张牌”的禁止计数，建议对照官方 FAQ 复核后再改代码。

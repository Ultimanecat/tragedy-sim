# 矩阵重要性提议（2026-10-13）

## 目标与边界

继续 [共同概率目标](unified-belief-target.md)。本阶段修正提议偏差和重复质量，不调整先验选择、软分系数、候选策略、行动评分或 horizon。矩阵开发开关默认仍关闭；终猜完整 MAP 独立于提议批次。

本文下方实验使用历史等权变体提议（uniform）。后续新增 [先验质量提议](prior-mass-matrix-proposals.md)（prior），开发开关开启时默认选择 prior；主线矩阵开关仍关闭。新旧均显式记录 q 并保持同一目标，下方历史公式和结果不能当作 prior 的实验。

`matrix_proposals=True`／`--matrix-proposals` 对非完整枚举 FS／BTX 身份库采用新路径，替代此前“旧提议不足时补样”。现有少角色枚举及关闭开关的旧路径保留。新路径不静默混入没有 q 的旧持续库，不新增大厅 AI 模式。

## 提议分布和估计器

1. 公共证据及硬 witness 生成剧情／数量／角色域变体。
2. 在 V 个有支持的变体中等权选择，再按剩余可完成分配数生成完整角色分配。变体内均匀，`q(world)=1/(V*N_v)`。
3. 完整 validator 和角色硬 matcher 继续过滤。残余拒绝的共同接受常数在自归一化重要性权重中消去；硬域仍为空时显式诊断，不放松。
4. 每次有效提议保留 q，允许重复，按 `target(world)/q(world)` 计算质量。同世界聚合时求和。
5. 每个根重建至多 `min(64, capacity)` 个有效提议，尝试上限 `max(64, count*12)`；当前没有跨根重用旧无密度库。
6. 用这组质量抽取有限行动世界，之后当事人和暗牌继续原有流水线。

事件仅用一个满足重复限制、保留已知当事人的合法占位安排完成角色 validator 检查；回溯避免占用未来已知当事人而误判无解。搜索前事件当事人会由独立维度重新抽样。FS／BTX 内事件合法性独立于角色身份，该安排不构成当事人概率或新证据。合法当事人联合后验采样仍是下一项。

同一组规则 X 的输入次序不影响初始先验查找，本阶段补充了此索引回归。

## 诊断

`proposal_summary().importance` 记录估计器 `matrix-role-importance-v1`、有效提议次数、唯一身份分配数、按单次提议计算的 ESS 和最大标准化单次质量。唯一分配数与 ESS 分开；ESS 不等于实际搜索世界数。该读取不刷新或推进 RNG。

`matrix_proposal_worlds` 新语义为累计有效提议次数，包含重复，不能与旧去重补样计数直接比较。目标版本仍为 `uniform-printed-casts-v1`；所选先验及软似然尚未校准为真实剧作家分布。

开发根审计和冻结库重抽复用同一重要性批次。矩阵的玩家观察边界保持；内部候选身份、q 和开发真值不进入玩家界面／SSE／公开 replay。

## 验证门槛

- 独立枚举 FS 可选暴徒 0–2 的不等大小分配空间，以精确提议频次作积分，校正后概率与目标一致；带软证据时同样成立。
- 实际随机生成保留重复，返回密度与枚举空间一致；校正后的数量组质量接近枚举目标。
- 密度非法时拒绝，硬 matcher／数量反例仍拒绝；已知未来当事人及连续杀人重复限制有反例。
- 提议／旧库不混合，原提议 RNG 不被新路径推进；诊断复制、冻结重抽和规则 X 次序有回归。
- 完整后端及串行对弈，原基线与留出剧本／seed 分开；只有完整报告作胜率对照，每局 replay 和公开证据兼容性复核。

## 后续

先看 ESS、危险支持、耗时和回退，校正正确不自动证明有限 64 次提议足够。补批次和危险分层必须保持权重，不能用定向添世界而不修正概率。小角色枚举的事件占位遗漏、特殊额外角色 MAP／完整先验计数继续审计；随后 U3 的合法当事人联合采样及 U4 的自适应搜索。

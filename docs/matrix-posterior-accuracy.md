# 矩阵后验精度与固定批次（2026-10-13）

## 为什么做这项实验

64 次矩阵提议在秒级对弈中出现两组胜负改善，固定工作量未延续；终猜分数也有升降。先在共同公开证据上比较推断误差，分离有限采样、行动估值及不同轨迹的信息差异。完整对弈见 [跨剧本比较](matrix-cross-script-comparison.md)。

`benchmarks.ai_matrix_posterior_accuracy` 不运行行动搜索，不输入真实剧本。独立排列加 printed validator 枚举七角色 FS 可选暴徒空间及 BTX 剧情空间，独立统计每剧情初始分配数，与生产 prior 分母核对。然后分别应用相同硬证据和 soft score，计算规范化精确目标。原始先验和软系数保持不变。

FS 初始 2310 个完整分配；增加“女学生为主谋”硬观察后 330 个。暴徒数量 0／1／2 的精确质量约 9.09%／36.36%／54.55%。BTX 固定已知爆弹／好友圈、其余副剧情未知，完整分配 6300 个。所有场景均七角色，确保实际走有限提议路径。

每个公开状态分别运行 16 个 seed，旧路径和矩阵顺序交替。比较完整加权候选的角色边际、剧情组合与暴徒数量概率；未采到支持的质量计入误差。TV 距离为各类别概率差绝对值总和的一半。与“对真实身份的猜中率”分开：这里衡量对既定模型的数值误差，不验证先验适合人类编剧。

## 64 次批次发现的方差

矩阵 64 次的平均角色 TV：FS 无观察 0.106、硬观察 0.073、软观察 0.112；对应旧库为 0.093／0.061／0.102。矩阵有限批次在这三个简单 FS 状态略差，不能用提议正确性消除方差问题。BTX 剧情 TV 则旧约 0.30、矩阵约 0.11～0.13，反映旧有限库的提议质量未作密度修正。

## 固定批次上限 192

旧路径每次向持续库补最多 64 个；矩阵每次用全新重要性批次替换整个库。把这两种流程沿用相同的 64 限制会使新批次偏小。现改为预先固定 `min(192, capacity)`，保留较小 capacity 的开发控制；不根据当批 ESS／权重决定停采，不放松硬 witness，不修改 q／target、行动世界数或节点预算。额外时间单独记入证据维护。

| 公开状态 | 旧库角色平均 TV | 矩阵 192 角色平均 TV | 旧／矩阵剧情 TV |
| --- | ---: | ---: | ---: |
| FS，可选暴徒，先验 | 0.0930 | 0.0595 | 0／0 |
| FS，同空间＋硬身份 | 0.0607 | 0.0426 | 0／0 |
| FS，同空间＋软亲友证据 | 0.1024 | 0.0631 | 0／0 |
| BTX，部分已知剧情，先验 | 0.1355 | 0.0642 | 0.3001／0.0579 |
| BTX，同空间＋软亲友证据 | 0.1430 | 0.0704 | 0.3042／0.0701 |

五类状态各 16 seed，角色平均 TV 均下降；这是本批合成状态上的精度结果，不代表所有 witness／规则集的误差保证。矩阵新批次平均准备约 46～94 ms，旧路径约 3～19 ms。矩阵用了更多提议，不能称为等采样工作量或更快；既定整体响应预算是否合适仍由对弈测量。

参考枚举不使用矩阵数量 DP／角色域。soft score 沿用生产 witness 定义，实验只验证采样逼近同一目标；不对 soft 系数做正确性背书。特殊额外身份另有支持集独立枚举测试。本实验仅首个刷新，不评估持续旧库经过多天的分布。

## 后缀计数缓存

原生成器对每个角色候选、每次抽样重新构造精确计数 DP。新增最多 4096 项的后缀计数缓存：键包含规范化角色集合、每列允许域、剩余身份数量、亲友性别限制及已占用性别。计数与角色处理顺序无关，随机角色顺序和所有 RNG 调用保持。

对实际 BTX-02G 的 192 个提议，缓存开／关的完整假说、q、policy 和最终 RNG 状态完全一致；反例覆盖允许域、剩余数量及不同性别占用，不可错误复用。16 seed × 五类状态 × 两种路径的 160 行试验结果，除耗时外所有字段与未缓存版完全相同。

缓存后 192 次矩阵准备均值为 FS 约 15～17 ms、BTX 约 27～28 ms，原未缓存为 46～94 ms。随后用同一缓存源码、capacity 64／192 重跑两组五类状态，隔离批次变化；旧路径的所有精度数值相同，192 次的精度改善保持。该缓存仅加速计数，不调整后验或抽样分布。

最新两个报告：`matrix-posterior-accuracy-192-cached-16trials.json` 与 `matrix-posterior-accuracy-64-cached-16trials.json`，位于同一忽略目录；二者 Python 指纹相同。历史对弈对应旧 64 次源码，不能当作 192 次新批次的胜率结果。

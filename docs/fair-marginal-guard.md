# 公平红方的合法单牌攻击覆盖（2026-10-16）

## 实现与边界

新增可选 `dark_card_policy="marginal_guard"`，默认仍sampled，adversarial_guard保留作对照。候选算法独立配置，本阶段固定 `candidate_policy="joint_threat"`。新增覆盖同时供轻量排序和真实引擎评价使用，短名单内容可随覆盖变化。

`marginal_guard_worlds` 对每个原后验抽样构造：原暗牌＋既有有限攻击模板＋每个公开槽位的全部合法单牌边缘探测。每个探测都是满足物理牌all-different的完整三牌，必要时调整其余槽位腾出牌；尊重公开已知牌、禁用牌、限次消耗和红牌前缀。按完整物理牌签名去重、保留第一项及原实体资源，原始样本本身保留在组首。

这保证逐槽／逐合法牌面的覆盖，不保证全部三牌联合组合完备。没有加入剧本ID或特定角色的行动定式。原攻击模板保留；身份／当事人质量、角色矩阵、witness、终猜、采样RNG都不更新。额外场景是攻击分支，不是后验样本。

评估仍先在每个原后验抽样内对暗牌／技能路线取最差，再按原质量聚合。此模式增加实际模拟与轻量投影，不能称与旧版等CPU预算；node_limit是候选数量，墙钟仍为软截止。

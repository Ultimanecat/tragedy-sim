## 2. 小矩阵的精确解与核验

对红方最大化的收益矩阵A，加常数使`B=A+shift>0`，求：

```text
maximize  sum(z[j])
subject to Bz <= 1, z >= 0
```

正矩阵提供可行的松弛基初值，使用Bland次序选择入基／出基变量。归一化原始解得到黑方分布y，归一化对偶解得到红方分布x，值为`1/sum(z)-shift`。返回前检查原始／对偶目标相等，并独立用原矩阵逐条验证：

```text
sum(x) = sum(y) = 1, x >= 0, y >= 0
x'A[:,j] >= v       对所有受限列j
A[i,:]y <= v        对所有受限行i
```

全部运算使用有理数，数值误差界为0。JSON同时给`fraction`与浮点`value`，证书以分数字段为准。有限浮点输入按其十进制文本解释为有理数，证书针对该输入值。没有新增第三方数值依赖；小矩阵LP的精确解不覆盖尚未加入的行动。

## 3. 全域最优回应与Double Oracle

每次解受限矩阵得到x、y，先找黑方整套牌面的最优回应，再找红方完整三牌的最优回应。非零支持外的收益无需查询；已知反例与初始化策略可以优先检查，其余合法域仍完整保留。默认初始化取公开合法域的首个行动，不读取实际暗牌。

已知收益范围为`[umin,umax]`。未计算的单元格及未遍历行动保留该范围；加权部分和提供候选的上下界。只有证明候选不能改进当前结果，或达到效用极值，才停止该分支。能力树未完成的收益不写入精确缓存。

```text
L = min_b sum_r x[r] A[r,b]
U = max_r sum_b y[b] A[r,b]
gap = U - L
```

回应尚未完成时，用其可靠区间更新L或U。保留历史最强下界及对应红方分布、历史最强上界及对应黑方分布；两份分布可以来自不同轮迭代。只有`gap=0`才认证该声明模型的最优值；`gap<=epsilon`给epsilon认证。世界／行动域不完整时不赋予完整模型认证。

节点、时间、单元格、LP pivot或迭代预算耗尽均返回现有可靠界，未完成tableau不返回认证。时间是软截止，单次原子结算／pivot可小幅超时。`best_response_complete`与`domain_exhausted`分开：效用极值可提前证明最优回应，无须物理访问每个行动。

黑方暗牌在红方本次随机抽牌之前已固定。求的是`min_b E_x A[r,b]`；逐次抽中红牌后再替黑方重选牌面会错误削弱混合策略。揭牌后的合法能力可以按规则响应实际红牌。

## 4. 独立验证

- 抽象匹配矩阵`[[1,0],[0,1]]`：纯策略保障0，均匀混合价值1/2。
- 正负、矩形、退化、分数和石头剪刀布矩阵；固定seed0–9的40个小矩阵，与独立高斯消元枚举顶点的原始／对偶解核对。
- Double Oracle与独立完整矩阵解比较；覆盖预算中断、恢复、未知收益、非法支持、缓存淘汰和不完整声明模型。
- 真实引擎构造FS小局面：完整240行×6列，全部纯策略保障0，混合价值2/3，与完整收益矩阵枚举结果一致。此测试使用受控手牌／弃牌，不代表正常官方剧本可达局面。
- 上述局面中的合法无效果黑牌可以作第三种掩护。如果只保留两种显著移动，得到的1/2会漏掉完整域的2/3；无效果牌不能未经证明就删掉。
- 完整安静FS根、同信息根替换实际暗牌后的固定工作量等价、CLI精确分数与可执行联合牌序列均有回归。

验收：混合策略专项31项通过；完整回归993项通过（310.546秒，日志`references/exact-day-mixed-regression-20261017.txt`）。全量回归与独立原生核验并发运行，该耗时不作空闲性能基准。

## 5. 压力根与复现

根来自FS01历史seed2、第2轮第2天出牌阶段，6角色，黑方靶位为女学生／职员／医生；红方368640套完整三牌、黑方504套合法牌面。初始化两套历史防守候选，仅作支持集种子，完整行动域未收窄：

```text
c 禁止移动→女学生；a 禁止密谋→职员；b 纵移→巫女
c 纵移→女学生；a 不安−1→职员；b 纵移→警察
```

两套纯策略各有失败攻击，混合策略可覆盖更多攻击。该根用于测量完整搜索和保障率，不作为整局胜率样本。冻结源码指纹`32ae8798…`，空闲串行测量：

| 时间预算 | 全域值区间[L,U] | gap | 已解受限矩阵 | 实际收益计算／未完成 | 停止原因 |
| --- | --- | --- | --- | --- | --- |
| 10秒 | [0,1] | 1 | 2×2 | 284／1 | time_limit |
| 60秒 | [1/2,1] | 1/2 | 2×3 | 3194／1 | time_limit |

60秒档给两套防守各1/2概率，黑方最优回应已覆盖全部504列，确认该分布的保障为1/2。红方最优回应只遍历2332／368640套，尚未排除更好的防守，因此不能宣称该根最优值为1/2或红方无解。当前主要成本在完整红方最优回应及其日末能力树；受限矩阵仅3次pivot即可求解。

随后独立核验使用4个进程、reference后端及原生`Game.transition`，不使用精确值／牌效缓存：504列全部通过，共实际计算509个收益单元格。未计算的混合成员按收益下界0处理；五列已完整计算且恰为1/2，因此返回红方分布的精确保障确为1/2。核验中红方不存在非平凡的揭牌后能力选择，这个分布的保障没有依赖私密能力使用历史选招。该事实不消除通用续演模型的信息集限制。

原始报告为`references/ai-calibration/2026-10-17/mixed-day-release-{10s,60s}.json`及`mixed-policy-independent-audit.json`。不将并发核验时间与上述串行性能比较。

```powershell
python -X utf8 -m benchmarks.ai_exact_day --mode mixed --backend cached --scenario official-fs-01-first-script --report references/ai-calibration/2026-10-16/fair-residual-production-10seeds.json --variant joint_candidates_residual_marginal --seed 2 --loop 2 --day 2 --nodes 100000 --time-ms 60000 --warmstart references/ai-calibration/2026-10-17/mixed-day-seeds.json --epsilon 1/100 --output references/ai-calibration/2026-10-17/mixed-day-release-60s.json
python -X utf8 -m unittest tests.test_day_game_matrix tests.test_day_game_zero_sum tests.test_day_game_mixed_engine tests.test_ai_exact_day
```

`--warmstart`为JSON数组，各项为完整三条`play`命令组成的数组；每条含actor、action、card、target。`--report`恢复指定历史出牌根，报告包含`root_setup_commands`及剧本指纹。`references/`继续忽略，新clone可省略report／warmstart从剧本初始合成根运行，但不再是同一压力测量。

下一阶段T0.4按世界分块计算黑方回应，根红牌共用分布，保留原后验质量；续演使用观察一致的政策或真正的信息集模型。随后按T1–T3替换日末叶值并扩展跨日／跨轮回。每次求解中冻结效用、后验更新和续演模型；旧0/1缓存不跨效用版本复用。

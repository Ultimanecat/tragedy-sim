# 按硬兼容先验质量提议（2026-10-13）

## 为什么继续优化

[联合当事人三路径对照](joint-culprit-posterior.md) 尚未证明矩阵棋力更优。角色提议当前逐个数量／允许域变体等权选择，再以 target/q 修正，有限批次中初始先验与硬兼容质量不一致会增加重要性权重方差。下一切片只改提议，不改先验、witness 软分、行动估值、horizon、64 次提议和 12 个行动世界。

## 两种可比较的提议

设变体 v 有 N_v 个可完成分配，该剧情组合初始有 C_p 个印刷合法分配；共同目标的单个分配初始先验为 1/C_p。保留现有目标 `uniform-printed-casts-v1`。

- 历史 uniform：V 个变体等权，变体内均匀；`q(s)=1/(V*N_v)`。
- 新 prior：变体权重为 `N_v/C_p`，总质量 `Z=∑ N_v/C_p`；变体内均匀，`q(s)=1/(Z*C_p)`。

矩阵没有完全投影的硬关系仍由完整 matcher／validator 拒绝；接受率的共同归一化常数在自归一化重要性权重中消去。变体对应不同剧情／完整身份数量／额外身份配置，完整世界不能重复属于多个变体。

软证据缺席、印刷计数精确且变体支持就是硬兼容空间时，新 q 等于目标后验，单次 target/q 为同一个常数，ESS 等于提议次数。软证据存在时重要性权重继续包含 `2**soft_score`，不直接改矩阵硬域；较高 ESS 仍不保证危险世界覆盖或棋力。

## 接口和诊断

`matrix_variant_policy="uniform" / "prior"` 为开发消融参数；评测 `--matrix-variant-policy` 同名取值。公平主线默认启用 prior 矩阵提议，最新精度与对弈验收见 [默认验证](matrix-default-validation.md)。少角色枚举、终猜 MAP 和当事人后验不受此参数影响；不新增长期大厅 AI 模式。下方实验属于 64 次批次历史切片。

每次 RoleProposal 同时记录 q 与 policy，重要性批次诊断记录策略集合；矩阵支持、初始计数和目标权重同源。传给提议器的目标复用因子信念已创建的对象，不重复建立不同先验。

开发冻结库保留原 q，逐步重建按对局记录的策略执行；历史缺字段报告使用 uniform。来源变更仍需核对是否重现原批次，不能把 q 数学一致当成旧随机序列一致。

## 验收

- 独立排列／validator 枚举检查不等大小可选人数空间：prior 采样质量随合法分配数变化，q 与参考一致，无软证据 ESS=N；uniform 作为方差对照。
- 多剧情＋硬身份观察的独立完整目标检查：prior 的 q 与硬条件化目标相同，保持所有硬 matcher；软 witness 不改变 q，只影响 target/q。
- 重复质量、非法策略、readonly 诊断及评测策略记录有回归。
- 全量后端通过后，串行同源码 uniform／prior 对弈；联合当事人保持固定，先在 BTX-01G／BTX06 多 seed 检查，再补留出和 Easy。

还需审计少角色枚举因随机事件占位漏支持、特殊额外角色 MAP／初始计数及后期有限世界覆盖。未达到默认切换门槛时继续优化，不从单局成功推导优势。

## 首批正确性与提议质量

51 项专项通过；最终完整后端 729 项通过（160.172 秒），前端未改。身份初始目标版本不变，uniform 的随机变体选择保持原等权规则。

`matrix-prior-quality-historical.json` 在已完成三路径 12 局的全部 151 个每日根上，用相同公开观察与角色 witness、同一目标，对比 64 次 uniform／prior 提议。该工具只重新提议身份，不搜索行动，也不改变原对局；每个根先核对真值硬兼容，真值不传给生成器。来源 `f448dd7b623ff38798896e859c337276d54b62d31af5c712245e803062e40092`，输入历史对局来源 `a38376f791fc0048bfa698c5b201c87dcd4427322ccab158517facdd1a9f9037`。

| 指标 | uniform | prior |
| --- | ---: | ---: |
| 最低 ESS | 12.536 | 20.253 |
| 平均 ESS | 46.696 | 53.625 |

151 根全部各抽满 64 次；111 根 ESS 改善、24 根下降、16 根相同。单批 ESS 有抽样噪声，观察之间有相关性；该表证明这批历史观察上的多数方差改善，不能称为 151 个独立对弈，也不证明普遍优于 uniform。实战 uniform／prior 八局配对另做，联合当事人固定开启，避免同时改变两层。

所有八局无出牌回退，107 个每日根矩阵保留真实身份／当事人，1578 条命令后真实世界硬兼容，完整 replay 重演通过。开发真值仅在对弈完成后的审计使用。uniform 的个别终猜数量与上个源码版本有波动，墙钟结果和样本噪声仍需固定工作量／更多 seed 检查，不能将其归为新先验。

当前结果支持继续以 prior 为矩阵开发主线。下一门槛是少角色完整支持与额外身份 MAP／初始计数审计，以及 BTX-02G、历史 BTX04、FS 留出和 Easy；默认主线保持旧路径，跨剧本验收后切换。

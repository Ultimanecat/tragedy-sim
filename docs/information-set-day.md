# 信息集日末博弈：序列形式与原生能力树（2026-10-18）

T0.4已增加精确序列形式求解器、原生FS能力树，以及有限根牌集的联合出牌／能力优化诊断。默认AI、房间和SSE不变。后续[完整域信息集回应器](information-set-responses.md)已独立接入；本页的`selected`受限根结果不能替代全域L/U。

## 1. 信息与行动契约

红方收到授权团队视图、自己的命令记忆、合法菜单和实际可见的选项文字。信息集键不含世界标签、私密剧作家命令数量或未揭牌面。剧作家读取自己的授权私密视图、自己的命令和菜单；不能读取红方尚未揭示的随机选牌。

每方另有自己的recall链：记住上次决策时所见的信息集及自己实际选择。相同当前投影、不同过去私密答案仍可区分；对手隐藏步骤不写入己方recall。只有一个合法动作的原生步骤可以从LP中消去，其观察和己方动作仍更新recall。树构建器独立检查同一信息集的行动集合及前置己方序列一致，违反perfect recall时拒绝求解。

根出牌结构为：自然选择setup类型 → 剧作家提交兼容历史／完整黑牌 → 红方从共同三牌策略中抽样 → 按原生引擎揭牌和结算。相同红方信息集跨世界共用技能策略，获得不同合法观察后再分支。所有可选顺序、拒绝及事件选择保留；没有将各世界的开眼技能最优值平均。

## 2. 精确LP与原约束验证

`sequence_form.py`从有限树构造双方序列与流约束：`E x=e`、`F y=f`，x/y非负；e/f只有根分量为1。终局收益乘自然概率，汇入对应的序列对矩阵A。纯策略的笛卡尔积不参与生产求解。

基础序列形式参考 [von Stengel，1996](https://doi.org/10.1006/game.1996.0050)，辅助阅读为 [ADFOCS讲义](https://conferences.mpi-inf.mpg.de/adfocs-24/material/Bernhard/2ext-adfocs.pdf)。以下可行原点的齐次变换是本项目实现路径，另由独立正常形式枚举核验。

首先给**每个终局收益**加相同shift使其严格为正，按原自然概率构造B。稀疏矩阵的所有格子直接加常数会改变博弈，禁止使用该变换。

```text
maximize t
B z - Eᵀ w <= 0
F z = t f
eᵀ w <= 1
z,t >= 0; w free
```

w拆为两个非负向量，等式拆为两条零右端不等式。除最后的1以外右端全为0，松弛原点可行，复用有理数Bland单纯形，无需另建Phase I。约束数为`N_red_sequences + 2 N_black_flow_rows + 1`，变量数为`N_black_sequences + 1 + 2 N_red_flow_rows`。当前是小型稠密实现，表格单元数、pivot和时间均受限，不承诺显式树很小时总能快速完成。

解中恢复黑方`y=z/t`、红方`x=α/t`及值`1/t-shift`；α为前一组约束的对偶乘子。独立复核：

- 双方原始非负实现向量及每条归一化流约束。
- `Eᵀ u >= B y`与`Fᵀ v <= Bᵀ x`的每条原序列约束。
- 双方根对偶值相等，且等于候选策略的精确期望值。
- 未平移的原始终局期望等于返回值，数值误差为0。

该误差范围仅针对所定义有限树和有理数叶值。它不校准角色软似然，不保证近似叶值等于真实整局胜率。

`behavioral_policy`把序列实现概率恢复成每个信息集的合法条件分布；己方前置序列概率为0时使用均匀合法延伸。命令身份为规范JSON，可解析回原生动作。当前策略表是私有求解结果，未注册为大厅AI。

## 3. 未知、根域和证书

原生能力树被节点／深度预算截断时，将该分支保留为[0,1]叶子，分别解下端和上端树。遗漏setup原质量同样形成[0,1]的自然分支，不重新归一化。原生转换、树验证和LP可共享外层截止时间；LP超时、超过表格或pivot上限时返回不可用原因，诊断输出保留[0,1]回退，没有未核验的策略。

两种根分别处理：

1. `build_ability_information_tree`：牌已提交，完整枚举后续原生能力选择；setup覆盖仍须调用者明确声明。
2. `build_root_information_tree`：输入共同红方牌集和每世界黑方列集，同时优化根混合策略与后续技能。只有集合成员合法、唯一且数量等于完整域时，`root_domain_complete`才为真。

`InformationSolution.bounds`是**给定树及所选根域**的值区间。删减红牌和黑牌可能向不同方向改变博弈值；受限根的区间既不自动是全域下界，也不自动是全域上界，必须与`InformationTree`的范围字段一起解释。只有根域、类型和续演覆盖均完整且区间闭合时，才标记该当日模型的`certified_optimal`。

## 4. 独立验证

源码指纹`039cdd09…`：

- 10个固定seed的多阶段隐藏世界树，与独立穷举全部正常形式纯策略的矩阵解逐项比值一致。
- Kuhn三张牌小扑克：独立64×64完整策略矩阵与序列形式均得−1/18；序列形式每方13个序列。
- 盲匹配博弈值1/2，允许对手观察本次选择后的回应博弈值0；隐藏类型下共同决策值1/2，真正获知类型后值1。
- 非完美记忆、行动集合不一致、伪造流／对偶价格／值、非法概率及资源上限均拒绝未核验结果。

真实FS控制局面使用医生同区减不安防御自杀：

| 局面 | 每世界开眼最优 | 公平共同策略 | 原生逐动作复核 |
| --- | ---: | ---: | --- |
| 已知受害者，医生可用 | 1 | 1；跳过技能基线为0 | 正确救援 |
| 两种受害者／关键人物世界各1/2 | 各1 | 1/2 | 返回策略在两世界的最坏黑方回应值为1、0，合计1/2 |
| 上述局面允许先用社员自查 | 各1 | 1 | 查询或其拒绝区分世界后，再减正确受害者不安；两世界原生值均为1 |

最后一项包含可选拒绝的信息：杀手社员可以拒绝，关键人物社员无法拒绝。红方只在收到相应公开结果后使用不同动作。独立核对从原始`Game`重新执行策略分布，剧作家遍历全部原生回应，不读取序列LP的终局矩阵。

真实诊断同时跑了两世界结构校准和FS01公开后验前缀，均选择2套红牌及每世界2套黑牌：前者显式160节点、464个原生展开节点；后者183节点、500个原生展开节点。前者因保留1/10未知质量返回受限树[0.9,1]，后者还触及原生节点预算而返回[0,1]；两者的完整根域认证均为假。这些只验证接口及范围报告，不构成全域防守保证或对弈胜率。运行与回归并发，约1秒的观测不作空闲速度基线。

原始记录为忽略目录`references/ai-calibration/2026-10-18/information-*.json`，独立原生策略核对脚本为`references/audit_information_policy_20261018.py`。完整回归1078项通过（350.900秒，`references/exact-day-information-regression-20261018.txt`）；新增的求解器、原生能力树及JSON命令共21项测试。默认AI和既有入口保持不变。

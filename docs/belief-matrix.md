# 共用信念矩阵与构造恢复

`tragedy_sim/belief_matrix.py` 接收合法观察与 witness，生成独立快照；不接收真实 `Game` 或私密剧本，不使用随机数。当前用于公平红方的可选开发日志，以及联合黑方的公开身份域熵估计。相同约束支持也接入构造恢复与暗牌采样，见下文。主任务顺序见 [路线图](future-roadmap.md)。

## 已实现

- 身份：列为初始角色、行为规则集身份；当事人：日期 × 初始角色。
- 格子分别保存 `hard_status`（`always / never / unknown`）、`approx_probability`、概率来源、样本规模和约束来源。
- 一元硬事实投影为允许域，拒绝／排除事实投影为 never；singleton 域可标为 always。当前传播是保守外界，未表达的关系可能继续保留 unknown。
- 角色存在向量与数量上下界。存在概率从完整样本分配统计，不能使用边际概率行和；完整视图使用剧情槽位、额外身份与硬析取传播数量，缺少 setup 的旧诊断只使用一元外界。
- `role_pressure`、`role_route_pressure` 提取显式 AnyOf，保留强弱、来源和时间点。一个角色存在的硬析取可以确定存在向量，不能直接确定其中哪个角色的格子。
- 原始 witness 全部深拷贝保留，包括条件式、剧情和跨维关系；不能把矩阵当完整合法世界求解器。
- 病毒造成的杀人狂公开观察允许初始平民，保留病毒剧情前提；私密初始身份答案可以进一步确定。临时工替身映射回初始角色列。
- JSON 与中文文本开发输出；默认日志关闭，矩阵不进入玩家界面、SSE 或公开 replay。

## 双方复用的边界

红方：以主人公合法视图、自己收到的调查答案、采样世界统计构建。

黑方：调用相同 `role_domains`，输入已由 `_red_reply_view` 筛选的主人公视图；只补入由完成的公开查询必然推知的答案。真实角色表用于黑方自己的模拟，不能直接作为红方已知身份。黑方的熵仍是轻量硬域近似，尚未替换为完整相关后验熵。

## 采样接入

- `PublicStateDeterminizer` 把相同暗牌域传给 `DarkCardBelief.sample`；公开手牌与实体牌唯一约束在材料化时继续执行，不读取真实暗牌。
- `MatrixWorldSampler` 从剧情／数量变体的角色允许域生成完整分配，按可完成分配数抽样，再做剧本校验和完整 matcher。变体提议不是完整后验分布。
- `FactorizedBeliefState` 默认只在旧提议及条件构造均为空、已有身份库也为空时启用恢复。正常库保持原有随机顺序；恢复后的库明确标为非完整枚举。
- `matrix_recovery=False` 或 self-play 的 `--disable-matrix-recovery` 用于消融；记录尝试次数与产生世界数，证据维护不占行动搜索节点预算。
- 原始 witness 保留，硬条件没有松动；候选仍为空时按现有显式回退处理，不使用真实剧本补样。最终猜测继续原有整套合法 MAP。

本批测试、对局摘要和边界说明见 [接入验证](belief-matrix-validation.md)。

当事人硬域共用 `belief_culprit_constraints`：直接揭示、候选限制与事件发生时的阈值快照复用完整 matcher，A.I. 合计标记与兼职替身保留原规则。矩阵和因子采样器逐根使用相同候选；软的未发生观察不自动形成排除。历史日志必须附带当时 witness，不仅传采样频率。

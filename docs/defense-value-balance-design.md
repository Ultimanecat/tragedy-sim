# 防守估值平衡设计（2026-10-28）

## 目标

同时处理两类目标：

- 短期：当天不输，避免立即失败。
- 长期：阻止未来事故、完成能力铺垫、保留终猜信息，最终赢下整局。

原则：

1. 当日存活是约束，不是唯一最大化目标。
2. 已知身份威胁优先作为硬约束；未知身份只按后验概率计风险。
3. 生存概率超过安全目标后，额外生存不加分。
4. 无硬威胁时，固定保留资源给长期目标。
5. 最终目标是整局胜率，终猜信息和长期事故防守都进入估值。

## 威胁分类

新增结构化 `ThreatAssessment`：

```text
ThreatAssessment
- target            可能失败的角色或位置
- failure_kind      死亡 / 事故 / 规则失败 / 终猜失败
- role              key、killer、serial、friend 等
- confidence        hard / posterior 概率
- severity          失败后果
- deadline          最晚可防守日
- active_now        当前局面是否已经构成威胁
- defenses          合法防守动作
```

规则：

- `hard` 且 `active_now` 且有合法防守：硬约束。
- `hard` 但当前不活跃：高权重长期风险。
- 只有后验概率：按 `confidence × severity × 紧迫度` 计期望风险。

## 分层选择

动作选择按层执行：

### 第 0 层：硬约束

```text
如果存在已知必然失败，且某个行动可以防守：
    只在能防住已知失败的行动里选
```

这一层是过滤，不是加权。

### 第 1 层：生存饱和

```text
survival_score = min(1, 存活概率 / 安全目标)
```

超过安全目标后不再奖励。

### 第 2 层：长期进展

```text
long_term_score = Σ 义务进度 × 紧迫度 × 后果严重度
```

包括：

- 事故倒计时；
- 计数离阈值差多少；
- 能力链铺垫到哪一步；
- 关键人物位置；
- 为未来保留的牌。

### 第 3 层：信息和终猜

```text
info_score = 已知身份比例 + 后验质量 + 终猜整套全对概率
```

BTX 不能用“多活一天”代替终猜信息。

### 第 4 层：软风险

```text
expected_loss = Σ 后验概率 × 失败严重度 × 紧迫度
```

已知身份概率为 1；未知身份只按后验算。

## 评分形式

```text
hard_ok = 0/1
score = hard_ok * 1000
      + w_s * satisficed_survival
      + w_l * long_term_progress
      + w_i * information_value
      + w_f * final_guess_value
      - w_r * expected_loss
```

要求：

- `hard_ok` 是过滤条件，不能被别的分项抵消。
- `satisficed_survival` 饱和。
- 已知身份只提高 `expected_loss` 中的置信度，不直接把未知世界全当真的。
- 终猜价值和长期义务分开记录，便于审计。

## 资源规则

- 有硬威胁：允许临时挪用长期资源。
- 无硬威胁：每天保留固定资源做长期铺垫，例如一张牌。
- 长期义务接近截止：提高长期权重。
- 多个软威胁：按期望风险和截止日排序。
- 信息不足：适当提高调查和身份信息权重。

## 实现计划

状态（2026-10-28）：P0–P3 纯函数、P4 决策级选择、P5 叶值适配器已实现并有专项测试；P4 整局配对待做。

### P0 威胁分类

已实现 `tragedy_sim/day_game/threats.py`：

- `ThreatAssessment`：目标、失败类型、角色、置信度、严重度、截止日、是否活跃、硬/后验来源。
- `classify_threats`：硬角色（`known_roles`）与粒子后验分开；key/friend/time_traveler 为保护目标，killer/serial 为威胁来源；只有已知事故责任人触发事故威胁，不读剧本真值。
- 同区域威胁决定 `active_now`。

验收：控制局中能标出已知杀手、已知 key、未知可能杀手。

### P1 硬约束过滤

- 已实现 `filter_hard_actions`：调用方给每个动作的覆盖目标，存在活跃硬威胁时只保留覆盖至少一个硬目标的动作；无可行防守时返回全部动作并标记 `feasible=False`。
- 这条过滤不硬编码具体卡牌；卡牌到威胁目标的覆盖由行动层提供。

验收：硬威胁存在且覆盖可算时，只保留覆盖至少一个硬目标的动作；无可行解时回退全部动作。纯函数测试已覆盖。

### P2 生存饱和与长期预算

- 已实现 `satisficed_survival`：`min(1, probability / target)`，超过目标不再加分。
- 已实现 `DefenseValue`／`score_defense_value`：硬约束主项 + 生存饱和 + 长期 + 信息 + 终猜 - 期望损失。
- 已实现 `long_term_slots`（硬威胁时不保留，否则保留固定槽位）和 `deadline_urgency`（截止日越近越高）。
- 长期预算真正占用哪些牌仍待接行动层。

验收（长期预算待完成）：

- 已知长期自杀风险 vs 未知低概率杀人狂：优先长期铺垫。
- 已知立即杀手：优先硬防守。

### P3 终猜与信息项

- 已实现 `information_value`：已知身份比例 + 存活角色后验集中度。
- 已实现 `final_guess_value`：存活角色最高角色概率的均值，作为终猜的廉价近似。
- 尚未接真实整套终猜概率和 T1 叶值。

验收：不会为了多活一天放弃终猜信息。

### P4 配对验证

决策级配对已完成：

- `select_defense_action` 合成 P1/P2/P3：硬过滤 → 分层评分。
- 已知活跃硬威胁时，即使其他候选长期分更高，也选择覆盖硬目标的动作。
- 无硬威胁时，生存已饱和的情况下长期铺设胜出。
- 硬威胁不可防时回退软排序，并标记 `hard_ok=False`。
- 专项 4 项通过。

整局配对仍待做：

- 固定 BTX01、固定黑方、seed 0–9。
- 旧基线：普通粒子。
- 新基线：分层估值 + 现有粒子行动。
- 分阶段记录：
  - 最终胜率
  - 当日存活率
  - 已知威胁覆盖率
  - 长期义务完成率
  - 终猜正确数
  - 决策耗时

不通过配对验证不切换默认 AI。

### P5 跨日接入

- 已实现 `DefenseLeafEstimator`：读取终局 winner、公开视图和可选 `BeliefSnapshot`，输出分层叶值。
- 可直接传给 `search_two_day(leaf_value=...)`；已有集成测试。
- 当前仍是已知世界诊断搜索的叶值；公平信息集路径要继续通过 snapshot 传入公开信念。

## 指标

- 最终胜率
- 最终日存活率（辅助）
- 已知威胁覆盖率
- 长期义务完成率
- 事故避免数
- 终猜整套全对率
- 每类动作的资源占比

## 风险

- 硬约束过强会把避免未知风险的动作全过滤掉。
- 已知角色可能当前没有威胁，不能无条件最高优先。
- 生存目标阈值需要校准。
- 长期义务完成率可能被“多堆友好”刷高，需要和最终胜率一起看。
- 权重不能只靠手调，要配对验证和消融。

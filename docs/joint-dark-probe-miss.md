# 黑牌联合探测遗漏的因果复查（2026-10-16）

## 结论

FS01 seed2、第2轮第2天的遗漏位于黑方攻击组合生成。该根红方联合枚举47904套牌，最终评价4个候选；每个身份／当事人样本只覆盖25套暗牌，公开合法暗牌共有504套。4个角色样本质量各.25，身份和当天谋杀当事人职员均已覆盖。

`marginal_dark_worlds`每次固定一个槽位的牌面，再由`_complete`优先保留另两个槽位原抽样牌面。它提供逐槽／逐牌覆盖，没有提供两槽联合覆盖。原抽样中的保护性黑牌因此掩盖了进攻。

生产算法未修改。本次只做同根只读重建、确定性结算和诊断记录。

## 同根四组控制实验

固定原角色／当事人假设：女学生关键人物、巫女杀人狂、刑警传谣者、职员普通人；当天谋杀当事人为职员。职员在都市，不安1、阈值2、禁止进入学校；女学生在神社。

红方固定：禁止密谋→女学生、横向移动→职员、纵向移动→巫女。医生的黑牌在四组中始终固定为横向移动。

| 女学生黑牌 | 职员黑牌 | 关键结算 | 当日主人公存活 |
| --- | --- | --- | --- |
| 纵向移动 | 不安−1 | 女学生到学校；职员不安降到0，能力加到1 | 是 |
| 斜向移动 | 不安−1 | 女学生到都市；职员不安降到0，能力加到1，谋杀不触发 | 是 |
| 纵向移动 | 禁止友好 | 女学生到学校；职员不安由能力加到2，谋杀发生，同区没有女学生 | 是 |
| 斜向移动 | 禁止友好 | 女学生到都市；职员不安由能力加到2，谋杀杀死同区关键人物 | 否 |

职员的红方横向移动最终目的地是禁入的学校，结算后留在都市。这个具体黑牌组合中，该红牌没有移走职员。不能据此全局删除所有撞禁行的移动：与对方另一方向移动合成时仍可能产生有效目的地。

最初发现的反例是`d女学生＋fg职员＋fp医生`。四组实验进一步将医生的黑牌固定为原`h`，证明只需要同时改变两个槽位；第三槽位没有参与这个必要条件。

## 评分器和真实结算核对

四组均用相同`incident_pressure:culprit=worker,key=girl,killer=student,day=2`路线和原续演种子生成方式，推进到当日边界或游戏结束。逐步记录了移动、计数物、剧作家能力、事件及失败。

- 前三组轻量风险为0，真实续演存活。
- 联合组合轻量风险为3，真实续演女学生死亡、轮回耗尽、剧作家获胜。
- 完整事件序列确认职员不安`1→2`、谋杀发生、女学生死亡；减不安对照则是`1→0→1`、谋杀未发生。

风险3是排序器的风险分值，不是概率。给出联合组合以后，轻量模型和真实引擎都能识别危险；该反例没有进入原25套探测集。

代码路径：`dark_attack_scenarios.py`的`marginal_dark_worlds`／`_complete`生成单因素补全，`particle_ensemble.py`把这些分支交给`HypothesisThreatRanker`和真实续演。候选条件化`refine_defense`目前只在开眼`joint_counterexample`模式调用，公平粒子路径尚未接入。

## 结论边界与下一步

另外验证了一个合法替代三牌“禁止移动→女学生、禁止密谋→职员、纵向移动→巫女”，在找到的反例和已选两条续演路线下存活。但其4×504联合暗牌的轻量筛查仍发现5个风险项，未证明它能对全部攻击存活。本次不据此宣称该根有统一必胜防守，也不把单一反例等同于实际黑方唯一选择。

下一步可复用已有候选条件化反例组件：针对少量完整红方候选，枚举／压缩合法黑牌组合，轻量筛选危险分支，再由引擎确认。确认的反例加入对应原角色／当事人组；所有红方候选在共同更新后的分支集重新评价，后验质量保持不变。需要验证该根最终可达到的最佳防守率及联合攻击成本。

不能只增加单因素模板数量：逐槽覆盖全部牌面仍会保留这类两槽条件。也不能把轻量风险0当作完整引擎的安全证明。新的攻击分支只用于规划压力测试，不进入witness或后验抽样计数。

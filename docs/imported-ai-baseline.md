## 首个明确缺口：FS 可选暴徒没有进入旧提议

FS-02G 真实职员身份为暴徒；旧搜索记录中没有暴徒样本，后期该角色可出现平民 12/12。这不是硬证据确定为平民，属于候选生成覆盖缺失。

三个专项反例均在旧代码上失败：

1. 已知主副剧情的小人数“完整枚举”只有 0 名暴徒，缺少合法的 1／2 名分配，真实角色表不在身份库中。
2. 全部身份明确揭示后，关闭矩阵恢复的因子信念仍返回零世界。
3. 普通构造提议无法生成暴徒。

矩阵的剧情／数量变体已正确支持 0–2 名；旧 `_role_slots` 仅包含固定剧情槽位，不能直接当完整身份人数配置。修复应提取共用的可选数量变体，接入旧枚举、随机构造与 MAP，保持验证及 matcher，防止继续把遗漏的库标为精确枚举。后续按同配置重跑 FS-02G；固定墙钟可能改变 RNG 分支，棋力影响还需多 seed 验证。
